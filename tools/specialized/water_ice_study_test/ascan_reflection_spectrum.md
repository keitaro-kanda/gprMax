# at_tx スペクトル解析ツール（`ascan_reflection_spectrum.py`）

**対象**：地表 tx/rx（at_tx、モノスタティック）で取得した A-scan
**位置づけ**：`ascan_spectrum.py`（埋設 rx・片道透過）の反射版
**版**：1.1（修正 6・7 を反映）

---

## 1. 何が変わるのか

`ascan_spectrum.py` は「1 深さ 1 トレース」で、**深さ方向にイベントが並ぶ**。
at_tx は「1 トレースに複数のイベント」で、**時間方向に反射が並ぶ**。

| | `ascan_spectrum.py` | 本ツール |
|---|---|---|
| 走査軸 | rx 深さ（12 点） | **反射イベント**（界面ごと） |
| 経路 | 片道透過 | **往復反射** |
| イベント分離 | 不要（1 トレース 1 波） | **時間ゲートが必須** |
| 振幅に効く項 | 幾何・地表透過・吸収 | 幾何・**往復透過**・**反射係数**・往復吸収 |
| α の意味 | 深さ d までの経路平均 | **往復経路の平均**（片道換算） |

**この差以外はすべて既存コードと揃える。**JSON の読み取り、ネスト階層の選択、参照計算の校正、組成・水氷濃度の自動判定、スペクトルのモーメントと LSR の規約はすべて `ascan_spectrum.py` から import して使う。定数のコピーは行わない。

---

## 2. 反射イベントの定義

レベルの構造から自動生成する。

| レベル | イベント |
|---|---|
| Level 1 / 2 / 3 / 3b | `surface`（d = 0） |
| Level 4 | `surface`(0) / `ice_top`(1.0 m) / `ice_bottom`(2.0 m) |

界面が 1 枚しかない Level 1–3 でも、**ノイズフロアの測定**と**地表反射の検証**のために実行する意味がある（§7）。

## 3. 理論

### 3.1 各イベントの伝達関数

界面 k（深さ d_k）からの反射は、参照 E_ref(f)（自由空間 1 m）に次を掛けたもの。

```
E_k(f) = E_ref(f) * G_k * T_k * R_k * A_k * exp(-2*pi*i*f*(t_k - R_REF/c))
```

| 項 | 式 | 備考 |
|---|---|---|
| G_k 幾何 | √(R_REF / r_eff,k) | rx は真空中なので √n は付かない |
| r_eff,k | **2h + 2 Σ_{j≤k} L_j / n_j** | 近軸の屈折則 r → r·(n_new/n_old) を往復に適用 |
| T_k 往復透過 | Π 4 n_a n_b/(n_a+n_b)² | 界面 k より浅い界面すべて |
| R_k 反射 | (n_k − n_{k+1})/(n_k + n_{k+1}) | Ez は界面に接線 |
| A_k 吸収 | exp(−2 Σ α_j L_j) | 往復 |
| t_k 走時 | 2h/c + 2 Σ n_j L_j / c | 往復 |

`r_eff` は既存の片道版 `n·h + d` と同じ規則から導かれる。地表反射（d=0）で r_eff = 2h となり、Level 1 の実測と一致する。

### 3.2 LSR

規約は既存コードと同じ。**LSR は振幅基準 ln|E|、モーメントはパワー基準 |E|²。**

| 種類 | 定義 | 意味 |
|---|---|---|
| **絶対 LSR** | ln\|E_k / E_ref\| | 参照計算に対する比。全項が入る |
| **相対 LSR** | ln\|E_k / E_j\| | イベント間の比。共通経路が消える |

### 3.3 減衰率の逆算

**絶対 LSR から（往復経路の平均）**

```
alpha_k = alpha_theory,k + [ L_abs,k(theory) - L_abs,k(measured) ] / (2 * d_k)
```

d_k は界面の物理深さ。地表反射は d=0 なので α は定義されない（スキップする）。

> **理論との差分で書く理由**：時間ゲートは実測と理論に同じものをかけるので、
> 差分を取れば窓による振幅損失が打ち消される。解析式
> `-[L - ln(G T |R|)]/(2d)` を直接使うと**ゲート損失がそのまま α の系統誤差**
> になり、深さ 1 m では 20% に達する（合成データで確認済み）。

> **注意**：この式は R_k を既知として使う。R_k は本来求めたい量なので、**これは順方向モデルの照合であって、実機で使える逆解析ではない。**

**相対 LSR から（層ごと・実測可能）**

```
alpha_layer = alpha_theory,layer + [ L_rel(theory) - L_rel(measured) ] / (2 * (d_k - d_j))
```

氷層の上面と下面の間で取ると、**|R_top| と |R_bot| は絶対値が等しい**ので比がちょうど 1 になり、T の比も氷上面の往復透過（10 vol% で 0.99943）だけになる。実質的に幾何項の補正だけで層内の α が求まる。**これが実機で使える形。**

### 3.4 tanδ への変換

既存の `alpha_to_tandelta()` をそのまま使う（α ∝ f の関係から）。

## 4. 解析項目

### 4.1 必須

| # | 項目 | 出力 |
|---|---|---|
| A-1 | **時間波形とゲートの可視化** | fig0 |
| A-2 | **生スペクトル・重心と幅**（既存 fig1 相当） | fig1 |
| A-3 | **LSR（絶対・相対）と理論の照合** | fig2 |
| A-4 | **減衰率と tanδ**（絶対・相対の両方から） | fig3 |
| A-5 | **群遅延** | fig4 |
| A-6 | **ノイズフロアの測定** | ログ・全図に水平線 |

### 4.2 A-1 が必須である理由

ゲートが正しい位置に張れているかを目で確認できないと、以降のすべてが信用できない。**理論走時の縦線とゲート窓を波形に重ねる図を最初に出す。**

`ascan_spectrum.py` にはこれに相当する図がない（1 トレース 1 波なのでゲートが要らなかった）。at_tx では新規に必要になる。

### 4.3 A-6 が必須である理由

反射イベントの振幅は地表反射より 27–58 dB 小さい（氷 10 vol% で −27.5 dB、0.5 vol% で −53.4 dB）。**フロアを測らずに「反射が見えた」と言うことはできない。**

#### 推定量：RMS ではなく分位点（修正 6）

励振波形は平坦帯域＋Tukey テーパなので、時間領域では sinc に近く**サイドローブが長く尾を引く**。実測では surface が 2–12 ns、ice_top が 14–24 ns、ice_bottom が 27–36 ns に広がり、**8–40 ns のほぼ全域がどれかのイベントのローブで埋まる**。

そこで RMS を取ると「数値ノイズ」ではなく「**励振波形のサイドローブレベル**」を測ってしまう。実測で −45 dB になったが、fig0(b) の静かな区間の実際の値は −80 dB 前後だった。

```python
NOISE_ESTIMATOR = 'percentile'     # 'percentile'（推奨）/ 'rms'（旧挙動）
NOISE_PERCENTILE = 10.0            # 包絡の下側 10% 分位点
NOISE_PERCENTILE_TO_RMS = True     # RMS 相当に換算する
```

純雑音の包絡は Rayleigh 分布に従うので、p 分位点は σ√(−2 ln(1−p))（p=10% で 0.459σ）になる。換算しないと分位点のほうが 6.8 dB 低く出て 2 つの推定量を比較できないので、**RMS 相当に換算している**。換算後は「純雑音なら RMS と一致し、イベントのローブがあるときだけ低く出る」という素直な量になる（純雑音での検証：RMS 9.990e-4 / 分位点 1.004e-3、真値 1.000e-3）。

#### 測定トレース：界面のないものを使う

```python
NOISE_TRACE_PATH = ''   # 界面のない at_tx（Level 3 など）の .out。
                        # 空なら解析対象自身で測る（参考値）
```

指定すると、そのトレースにも**同じ自由空間差分をかけてから**フロアを測る。解析対象自身で測る場合は既知のイベント時刻の前後 ±(ゲート半幅+1 ns) を除外するが、**サイドローブはそれよりずっと遠くまで伸びるので除外だけでは足りない**。

4 通りの組み合わせを合成データ（真の雑音 −80 dB 相当）で比較した。

| 測定トレース | 推定量 | フロア | ice_top の SNR |
|---|---|---|---|
| 自トレース | RMS（旧） | −41.8 dB | +14.0 dB |
| 自トレース | 分位点 | −68.5 dB | +40.7 dB |
| 界面なし | RMS | −33.8 dB | +6.1 dB |
| **界面なし** | **分位点** | **−80.0 dB** | **+52.2 dB** |

**界面なしトレース × 分位点**だけが真の雑音レベルを回復する。他の 3 通りはすべてサイドローブを測っている。

#### 時間分解フロア

fig0(b) に**包絡の移動分位点**（既定 2 ns 窓）を重ねる。水平線 1 本より情報量が多く、どの時間帯が数値ノイズに支配され、どこがイベントのサイドローブに支配されているかが読み取れる。

#### 判定：フロアの絶対値ではなく SNR

旧版はフロアの絶対値（−70 / −60 / −55 dB）で判定していたが、これは「地表反射比」という**基準量に依存する**。実際、直達波を差し引くと基準が直達波から地表反射に変わって 22 dB シフトし、同じデータなのに判定がひっくり返った（−67.4 dB「注意」→ −45.3 dB「不可」、しかし SNR は両者とも +17.8 dB で同一）。

判定は基準量に依らない **SNR** で行う。

```python
SNR_DETECT_DB = 12.0     # これ以上なら「検出可」
SNR_MARGINAL_DB = 6.0    # これ以上なら「限界」
```

イベントごとに判定してログと `run_info.txt` に出す。

### 4.3b 帯域端パネルを廃止した理由（修正 7）

旧 fig1 の (b) は各イベントの帯域内最大に対する −10 dB 交差（f_lo / f_hi）を描いていたが、**この量は媒質に反応しない。**

吸収による帯域内の傾きを計算すると、

| イベント | 帯域内の傾き | −10 dB に届くか |
|---|---|---|
| surface | 0.00 dB | NO |
| ice_top | 1.99 dB | NO |
| ice_bottom | 3.90 dB | NO |

**いちばん減衰の大きい ice_bottom でも 3.9 dB しか傾かない。**−10 dB のしきい値には原理的に届かないので、交差点は媒質ではなく**励振波形の Tukey ロールオフの位置**で決まる。実際に一点に潰れる、帯域端に張り付く、といった挙動になった。しきい値を下げても平坦部に入るだけで改善しない。

一方 **f_c ± σ_f は帯域内の全パワーを積分した量**なので、わずかな傾きでも確実に反映される。実測でも surface 1.25 → ice_top 1.21 → ice_bottom 1.17 GHz と単調に下がり、α ∝ f による重心シフトがそのまま見える。

したがって fig1 は **(a) 生スペクトル / (b) 重心と幅**の 2 パネルにした。f_lo / f_hi は `events.csv` には残してある。

### 4.4 直達波の除去（必須。既定 ON）

at_tx は rx が tx と同位置にあるため、**直達波（波源の近傍場）が地表反射より 22 dB 大きく**記録される。帯域制限波形は時間的に長い裾を引くので、2.3 ns 後の地表反射は分離できず、ノイズフロアも押し上げられる。

`_reference` の **`at_tx`（自由空間、地面なし）を差し引く**と直達波だけが消える。実機でもアンテナの直達結合は事前較正できるので、氷なしトレースの差分と違い**現実的に使える手法**である。

```python
SUBTRACT_FREESPACE = True          # 既定 ON
FREESPACE_AT_TX_PATH = ''          # 空なら JSON の _reference / at_tx を使う
```

**差分あり／なしの両方を出力する。**差分ありがメイン、差分なしは元データの姿を残すためサブディレクトリ `no_subtraction/` に出す。

効果の実測（合成データ、10 vol%）:

| | 地表反射の到達時刻 | 地表反射の \|R\| | ice_top |
|---|---|---|---|
| 差分あり | **7.345 ns**（理論どおり） | **0.258**（理論 0.268） | −27.74 dB（理論 −27.5） |
| 差分なし | 6.103 ns（直達波を拾う） | 0.415（理論の 1.5 倍） | −38.35 dB（基準が直達波） |

## 5. 時間ゲート

**本ツールでいちばん結果に効くパラメータ。**

| 設定 | 既定 | 根拠 |
|---|---|---|
| 半幅 | 2.0 ns | パルス幅 約 0.7 ns に対して十分。イベント間隔 11.6 ns に対して重ならない |
| 窓 | Tukey (α=0.2) | 既存コードと同じ。矩形窓のスペクトル漏れを避ける |
| 中心 | 理論走時 | 実測ピーク位置に合わせる選択肢も持つ（`GATE_CENTER = 'measured'`） |

**イベント間隔**（7.5 wt%、氷層 1.0–2.0 m）

| 区間 | 間隔 |
|---|---|
| 地表 → 氷上面 | 11.56 ns |
| 氷上面 → 氷下面 | 12.12 ns（10 vol%） |

半幅 2 ns なら窓は 4 ns 幅で、隣のイベントまで 7.5 ns 以上の余裕がある。

> **ゲート幅を広げると多重反射が窓に入る。**氷上面 → 地表 → 氷上面の多重は上面の 11.56 ns 後に来るので、半幅を 5 ns より広げると混入する。既定の 2 ns は安全側。

## 8. 既知の限界

| 項目 | 内容 |
|---|---|
| 多重反射 | 理論に含めない。残差に現れる。水平一様な構造だから見えるだけで、Level 6・7 では崩れるため検出指標には使わない |
| 絶対 LSR からの α | R_k を既知として使うため、実機での逆解析には使えない。**相対 LSR のほうが実測可能** |
| 層厚と屈折率の縮退 | 走時差だけでは分離できない。Level 8 の CMP で分離する |
| 斜め入射 | オフセット 0 前提。20 cm までは垂直入射で近似可 |
| 背景差分 | 実機では使えない。理論上限としてのみ |
| 直達波の裾 | 2D 線源のグリーン関数は長い裾を引く。差分なしのフロアはこれで決まる。§4.4 の自由空間差分で除去する |
| 波源遅延 | 励振ファイル自体が時間遅延を持つ。ゲート中心は幾何走時ではなく**理論トレースの包絡ピーク**を使う（`t_geom` と `t_theory` を両方出力） |
| ゲート依存性 | 幅を変えると α が動く。`GATE_SWEEP_NS` で確認すること |
| ノイズフロア | イベントのサイドローブに汚染されやすい。**界面のないトレース × 分位点**でのみ真の値が出る（§4.3）。判定は SNR で行う |
| 帯域端 f_lo/f_hi | 励振波形のロールオフで決まり媒質に反応しない。図からは外した（§4.3b） |

## 9. 既存コードとの共有

次はすべて `ascan_spectrum.py` から import する。**同じ値を 2 箇所に書かない**（修正項目 A-1 と同じ事故を防ぐ）。

```
ユーティリティ : load_paths / check_paths_exist / resolve_output_dir
                 load_trace / resample_trace / spectrum / measure_peak
                 _interp_complex_to_grid / save_figure
自動判定       : set_level3_composition / set_level4_ice
媒質モデル     : level3_eps / level3_alpha / level4_eps / level4_alpha
                 level4_targets / level4_ice_volume_fraction / refractive_index
                 describe_level3_medium / describe_level4_medium
スペクトル量   : moments / lo_hi_freq / log_spectral_ratio / alpha_to_tandelta
                 valid_mask / noise_floor / group_delay
定数           : C / TX_HEIGHT / R_REF / BAND_GHZ / BAND_CENTRE_HZ
                 FLOHI_THRESHOLDS_DB / LEVEL_EFFECTS / LEVEL4_ICE_TOP_M など
```

本ツール固有なのは **反射の伝達関数**（§3.1）と **イベント検出・ゲート**（§5）だけ。

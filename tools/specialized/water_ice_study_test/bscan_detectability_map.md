# detectability_map.py — 反射で検出できる水氷の最小濃度

氷層（厚さ固定）の**上端・下端の反射**で、水氷を検出できる最小の濃度 v_min を、氷層の深さの関数として求める。
使う計算結果は、水氷なしの B-scan 1 本と、水氷あり（pore 10 vol%、上端 1 m、厚さ 1 m）の B-scan 1 本だけ。どちらも同じランダム場で計算したもの。

2 段階で求める。

1. **案 C**：計算結果を、そのまま濃度方向に伸ばす。計算した深さ（上端 1 m・下端 2 m）でだけ v_min が出る。仮定は「反射は v に比例する」の 1 つだけ。
2. **案 A**：案 C の基準点の振幅を、閉じた式の比で深さ方向に動かす。v_min(z) の曲線と、濃度 × 深さの地図ができる。

案 A は、基準点で案 C と合うこと（目安は ±1 dB）を確かめてから使う。

---

## 1. 使い方

`bscan_detection.py`、`bscan_superposition_check.py`、`subsurface_model.py`、`ascan_spectrum.py` と同じフォルダに置いて実行する。

```
python detectability_map.py
```

| 設定 | 既定値 | 意味 |
|---|---|---|
| `JSON_PATH` | out_file_paths.json | 入力（bscan_detection と同じ） |
| `TARGET_CONDITION` | None | 氷ありの条件名。None なら基準以外で最初の条件 |
| `C_V_GRID` | 0–40 vol%、1 % 刻み | 案 C で合成する濃度（空隙を満たせる上限より上は自動で外す） |
| `C_GATE_FLAT_NS` / `C_GATE_TAPER_NS` | 2.5 / 0.5 ns | 氷の応答を切り出す範囲 |
| `AMP_HW_NS` | 1.5 ns | 基準点の振幅 A_sim を取るゲート |
| `A_V_GRID` / `A_Z_GRID` | 0.5–40 vol% / 0.20–2.95 m | 地図の格子（縦軸は**氷層の上端の深さ**） |
| `A_CALIBRATE` | True | 案 A′：余裕に定数 ΔM を足して、基準点で案 C に合わせる（§3.7）。False で較正なしの案 A |
| `A_PD_EXTRA` | () | 例 (0.9,)。P_D = 0.5 以外の等高線を足す（§3.6 の仮定 A4 が加わる） |
| `SURFACE_SKIP_NS` / `EDGE_GUARD_NS` | 5 / 1 ns | 使わない時間帯（地表反射の直後、領域の底の手前） |

- 入力の選び方、直達波の除去、トレースの範囲、反射チャネルの定義（ゲート、プール、5 % 誤警報）は、すべて `bscan_detection.py` の設定をそのまま使う。
- 計算時間：テストデータで約 35 秒（案 C 約 10 秒、案 A 約 20 秒）。

## 2. 検出の定義（bscan_detection と同じ）

時刻 t、トレース j ごとに、ゲート ±1 ns の中での包絡の最大値 P_j(t) を取る。

- **しきい値**：A_thr(t) = 水氷なしの P_j の 95 パーセンタイル（±0.5 ns とトレースをまとめて取る。誤警報 5 %）
- **検出確率**：P_D(t) = (P_j(t) > A_thr(t) となるトレースの割合)
- **界面での P_D**：界面の往復群走時 t_k の ± 1 ns の中での P_D の最大値
- **見える**：P_D ≥ 0.5

## 3. 原理式

### 3.1 氷の応答（両案で共通）

    ΔT(t) = T(t) − W[R](t)

- T：水氷あり、R：水氷なし。
- W[R]：R の時間軸を、氷層を往復する遅れ τ(t) だけ伸ばしたもの（`bscan_superposition_check` と同じ）。

  W[R](t) = R(t − τ(t)) · exp(−Δatt(t))

  - τ(t) = 2/c ∫ (n_ice − n_dry) dz：氷層より深いクラッタの遅れ。地表〜上端は 0、下端より深いと一定。pore 10 % では 0.57 ns。
- W を通すことで、氷層より下の「遅れて届いたクラッタ」が ΔT から取り除かれ、反射だけが残る。

界面 k（上端・下端）の走時 t_k のまわりを、窓 w_k（平らな部分 ±2.5 ns、外側に 0.5 ns のコサインテーパ）で切り出す。

    ΔT_k(t) = w_k(t) · ΔT(t)

### 3.2 案 C：濃度方向に伸ばす

    T(v) = R + Σ_k (v / v₀) · ΔT_k(t − [t_k(v) − t_k(v₀)])

- 振幅を v / v₀ 倍する。反射係数が小さい（|R| ≈ 0.02）ので、反射は v に比例する（§3.3）。トレースごとのゆらぎも、そのまま一緒に伸びる。
- 下端は、濃度で氷層の中の速度が変わるぶん走時がずれる。t_k(v) は平均媒質で計算する。
- T(v) を §2 の反射チャネルにかけて P_D(v) を出し、P_D = 0.5 を下から越える v を内挿で求めて **v_min,C** とする。
- 足すのは R（伸ばしていない水氷なし）だが、P_D はクラッタの「分布」で決まるので、W を通すかどうかは結果に効かない（確認済み、差 0.005 程度）。

### 3.3 反射係数（LLL 則）

c = ε′^(1/3) と書くと、pore ice では真空の一部が氷に置き換わるので

    c_wet = c_dry(z) + v (c_ice − 1),   c_ice − 1 = 3.15^(1/3) − 1 = 0.466

屈折率は n = c^(3/2)。上端の反射係数は

    R_top = (n_dry − n_wet) / (n_dry + n_wet) ≈ −(3/4) · 0.466 · v / c_dry(z) = −0.349 v / c_dry(z)

- v に比例し、深さには 1/c_dry を通して弱くしかよらない。
- 1 m・10 % で −0.0239（厳密値 −0.0235）。
- 下端は符号が逆で、下端の深さでの c_dry を使う。
- コードでは近似を使わず、厳密な式（`subsurface_model.interface_reflection`）で計算している。

### 3.4 案 A：基準点からの比

帯域中心 f_c = 1.25 GHz で、界面 k の振幅を 4 つの因子の積で表す。

    F_k(v, z) = |R_k| · G_k · |T_k| · L_k

| 因子 | 式 | 意味 |
|---|---|---|
| \|R_k\| | §3.3 | 界面の反射係数 |
| G_k | √( R_REF / (2h + 2∫₀^{d_k} dz / n) ) | 2D（線波源）の幾何学的な拡がり。屈折で拡がりが抑えられるぶんを ∫dz/n で入れる |
| \|T_k\| | ∏ (往復の透過係数) | 地表と、それより浅い界面を往復で通る透過。地表のぶんは深さによらない |
| L_k | exp(−2 ∫₀^{d_k} α dz)、α = π f √ε′ tanδ / c | 往復の吸収（tanδ は Carrier の式、氷層の中は LLL で混ぜた値） |

- d_k：界面の深さ（上端は z、下端は z + 厚さ）
- h：アンテナの高さ（0.35 m）
- n、ε′、tanδ：平均媒質（ゆらぎなし）の値

基準点 (v₀, z₀) = (10 %, 1 m) で測った振幅 A_sim に、この比を掛ける。

    A_k(v, z) = A_sim,k · F_k(v, z) / F_k(v₀, z₀)

- **A_sim,k**：ΔT_k の包絡の、ゲート ±1.5 ns の中での最大値を、トレースについて中央値を取ったもの。
- 比を取るので、far_1m からの絶対値の計算（2D の Green 関数、波源の較正）は使わない。
- 基準点そのものでは比は 1 になり、計算結果と完全に一致する。

### 3.5 余裕と v_min

    M_k(v, z) = 20 log₁₀[ A_k(v, z) / A_thr(t_k(v, z)) ]     [dB]

**M = 0 を P_D = 0.5 の境界とみなす**（信号の中央値 ＝ しきい値。仮定 A3）。

A がほぼ v に比例するので、v_min は

    v_min,k(z) = v₀ · A_thr(t_k) / A_k(v₀, z)

となる。下端は v で走時 t_k が少し動き、しきい値も変わるので、次の反復で解く（8 回。ほぼ 2〜3 回で収まる）。

    v ← v · 10^(−M_k(v, z) / 20)

v が空隙を満たせる上限 φ(z + 厚さ) = 1 − ρ / ρ_grain を超えたら、「空隙を満たしても届かない」とする。

### 3.6 P_D の曲線（案 A）

振幅のトレースごとのばらつきを、対数正規（dB で正規分布、標準偏差 σ_a）とみなすと

    P_D(v, z) = Φ( M(v, z) / σ_a )

- Φ：標準正規分布の累積分布関数
- σ_a：基準点での ΔT_k の包絡ピーク（dB）の標準偏差

figC1 の破線はこの式で描いている（基準点の σ_a を使う）。P_D = 0.5 では M = 0 なので、σ_a は v_min に効かない。
`A_PD_EXTRA` を使うと、σ_a を 2 つの基準点（上端 1 m・下端 2 m）を通る直線で深さ方向に内挿・外挿して、P_D = p の等高線 M = σ_a(z) · Φ⁻¹(p) を描く（仮定 A4）。

### 3.7 案 A′：定数 ΔM による較正（`A_CALIBRATE = True`、既定）

実データで案 A（§3.5）と案 C を比べると、案 A の v_min は案 C より系統的に大きかった。

| 基準点 | 案 C | 案 A | 差 |
|---|---|---|---|
| 上端 1 m | 6.55 vol% | 8.74 vol% | +2.51 dB |
| 下端 2 m | 7.60 vol% | 9.50 vol% | +1.93 dB |

**原因：** 実際の判定では、信号 s にクラッタ c が**足された**波形の包絡の最大値 max|s + c| をしきい値と比べる。しきい値付近ではクラッタも信号と同じくらいの大きさなので、足し合わせで包絡が持ち上がり、|s| < A_thr でも超えるトレースが出る。仮定 A3 はこれを無視しているので、v_min を大きめ（保守的）に見積もる。

**較正：** この持ち上がり分を、余裕に足す定数 ΔM で表す。

    M′(v, z) = M(v, z) + ΔM
    ΔM = mean_k [ 20 log₁₀( v_min,A,k / v_min,C,k ) ]      （2 つの基準点の平均）

- v_min は M′ = 0 から、§3.5 と同じ反復で求める。v_min′ ≈ v_min · 10^(−ΔM/20) となる。
- **ΔM を深さによらない定数とみなしてよい理由（仮定 A3′）**：持ち上がり量は「しきい値で割ったクラッタの分布の形」で決まる。しきい値は各時刻のクラッタの 95 パーセンタイルそのものなので、クラッタの強さが深さで変わっても、比の分布の形はほぼ変わらない。実データでは 1 m と 2 m の ΔM_k の差が 0.6 dB で、この見方と合う。
- 加わる量は、案 C から決める経験定数 1 つだけ。較正後は、2 つの基準点の残差が ±(差の半分) ≈ ±0.3 dB になる。
- figC1 の破線は Φ(M′ / σ_a)、点線は較正なしの Φ(M / σ_a)。

### figC1_pd_vs_concentration（案 C と案 A の比較：最初に見る図）

- 横軸は濃度、縦軸は P_D。
- 実線＋点が案 C（計算結果を伸ばしたもの）、破線が案 A′ の Φ((M + ΔM) / σ_a)、細い点線が較正なしの案 A、★ が gprMax の T そのものの P_D。
- 点鎖線は P_D = 0.5、点線は誤警報 5 %。
- **見るところ**：
  - 実線と破線が P_D = 0.5 を横切る濃度が近いか。数値は run_info.txt に出る。
  - ★ と、実線の v = 10 % の値が近いか（案 C が計算を再現しているか）。
  - 破線は σ_a だけで形が決まるので、裾の形は実線と違ってよい。比べるのは 0.5 の位置。

### figA0_ingredients（案 A の材料）

- **(a)** 濃度 10 % での信号 A(v₀, z)（実線）と、その走時でのしきい値（破線）。単位は dB re 地表反射。実線が破線より上なら、10 % で見える。
- **(b)(c)** 上端・下端について、基準点からの各因子の変化（dB）と、その積（黒）。どの因子が深さ方向の変化を決めているかがわかる（主に G と L）。
- 横軸はすべて氷層の上端の深さ。下端の曲線は、下端の深さ z + 1 m に対応する。
- しきい値のぎざぎざは、このランダム場 1 実現での 95 パーセンタイルのばらつき。平滑化はしていない。

### figA1_margin_map（濃度 × 深さの地図）

- 色は較正後の余裕 M + ΔM [dB]。赤は見える、青は見えない。
- **黒の実線が M + ΔM = 0（P_D ≈ 0.5）**。濃度について比例なので、黒線の左右の色の並びは各深さでほぼ同じ形になる。
- 灰色の破線は、空隙を満たせる上限。その右の灰色の領域は pore ice ではありえない。
- 上下の灰色は、走時が使えない深さ（地表反射の直後、計算領域の底の近く）。
- **★（金）＝ 案 C の v_min**。計算結果を濃度方向に伸ばして P_D = 0.5 になった濃度で、**シミュレーションした点ではない**。案 A′ と案 C が合っていれば、★ は黒線の上に乗る。
- **○（白）＝ シミュレーションした点**（10 vol%、上端 1 m）。黒線より右（赤）にあれば、計算の P_D > 0.5 と整合している。
- (b) の下端の地図も、縦軸は**氷層の上端の深さ**。

### figA2_vmin_curve（結論の図）

- 検出できる最小濃度 v_min（P_D = 0.5）と、氷層の上端の深さの関係。
- 線が案 A′、★ が案 C の v_min、○ がシミュレーションした点、灰色の破線が空隙を満たせる上限。
- figA0 (a) の信号としきい値は較正前の値。較正後の境界は、しきい値の破線を ΔM だけ下げた位置になる。
- 線より右（高濃度）なら、その深さで反射が見える。

## 7. 範囲と注意

- **固定している条件**：厚さ（計算と同じ 1 m）、ランダム場のパラメータ、2D、pore ice のモデル、組成（FeO + TiO₂）。
- **縦軸**：氷層の上端の深さ。下端の結果は、その 1 m 下の界面のもの。
- **しきい値**：水氷なしの計算 1 実現から取っている。深さ方向のぎざぎざ（±1 dB 程度）は、そのまま v_min のぎざぎざになる。
- **excess ice**：同じ式で扱えるが、基準点の計算が pore なので、案 C の応答をそのまま使うのは厳密でない。また約 1 m で反射が消える深さがある。今回は対象外。
- **層の中のクラッタ**：氷層の中でクラッタが少し弱くなる疑いがある（P_D が 0.05 を下回る件）。下端の直前のしきい値にわずかに効く可能性があるが、ここでは水氷なしのしきい値をそのまま使っている。
- **合成テストデータでの数値**：テストデータは Carrier のプロファイルで作っていないので、意味を持たない（コードの動作確認のみ）。

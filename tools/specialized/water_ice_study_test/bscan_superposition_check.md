# bscan_superposition_check.py — 差分トレースと解析応答の比較

## 1. 何を確かめるか

水氷ありの B-scan **T** を、水氷なしの B-scan **R**（同じランダム場）と解析計算だけで再現できるかを調べる。
再現できれば、検出可能域のマップ（濃度 × 深さ × 厚み）は、水氷なしの計算 1 本と解析応答の組み合わせで作れる。

| モデル | 合成 B-scan | 意味 |
|---|---|---|
| M0（単純な足し算） | R + S | クラッタはそのまま、反射だけを足す |
| M1（時間伸縮つき） | W[R] + S | 氷層より深いクラッタを、氷層を往復するぶん遅らせてから足す |

- **S（解析応答）**：氷層の上端・下端の反射。式は `ascan_reflection_spectrum.synth_theory` と同じ。

  S_k(f) = E_ref(f) · G_k · T_k · R_k · A_k · exp(−i2πf (t_k − R_REF/c))

  - E_ref：far_1m の実測波形
  - G_k = √(R_REF / r_eff)、r_eff = 2h + 2∫dz/n：2D（線波源）の拡がり
  - T_k：往復の透過係数
  - R_k = (n_上 − n_下) / (n_上 + n_下)
  - A_k = exp(−2∫α dz)
  - t_k = 2h/c + 2∫n dz/c
- **W[R]（時間伸縮）**：W[R](t) = R(t − τ(t)) · exp(−Δatt(t))
  - τ(t)：深さ z から来る散乱の往復走時の差（氷あり − 氷なし）。地表〜上端は 0、層の中では直線的に増え、下端より深いところでは一定。
  - Δatt(t)：往復吸収の差（帯域中心での値）。

## 2. なぜ M1 が必要か

pore ice を入れると氷層の ε′ が上がり、氷層より深い散乱体からのクラッタは遅れて届く。

- 10 vol%、深さ 1–2 m の場合：ε′ は 3.14 → 3.45、n は 1.77 → 1.86。
- 往復で τ ≈ 2 × 1 m × 0.085 / c ≈ **0.57 ns**（記録の値でツールが計算したモデル値は 0.570 ns）。

パルス幅は約 0.7 ns なので、0.57 ns ずれたクラッタどうしの差はほぼ無相関になる。
その結果、**T − R には、氷層より下のクラッタが水氷なしと同じくらいの強さで残る**。これは反射でも、ランダム性と反射の相互作用でもない。単に下のクラッタが遅れて届いただけである。

M0 で合成すると、下端の反射の周りと氷層の下でこの成分が抜け落ちる。M1 はこれを戻す。

## 4. 判定の目安（提案）

重ね合わせが成り立つとみなす条件。数値は run_info.txt に出る。

1. **上端**：差分の平均と S の差が ±1 dB 以内、走時のずれが ±0.1 ns 以内、相関が 0.9 以上。
2. **遅れ**：fig4 の実測が τ(t) に乗り、氷層の下で 0.57 ± 0.05 ns。
3. **残差**：窓ごとの表の `M1res/clut` が、layer と below で −10 dB 以下（クラッタのしきい値をほとんど動かさない）。
4. **P_D**：上端・下端での |P_D(W[R] + S) − P_D(T)| が 0.1 以下。

- **1 が外れる場合**：解析応答そのもの（2D の拡がり、透過、波源の較正）に問題がある。振幅の差が一定なら、較正係数 1 つで直せる。
- **2 が外れる場合**：時間伸縮のモデル（平均媒質の n）に問題がある。
- **3 と 4 だけが外れる場合**：ランダム性と反射の相互作用が無視できない。この場合は、シミュレーションが必要な領域だということになる。

## 5. 予想されるずれ（M1 で無視していること）

- **斜め方向の散乱**：アンテナ直下以外の散乱体は氷層を斜めに通るため、遅れは τ / cosθ と少し大きい。M1 の残差は氷層の下で少し残るはず。
- **地表反射の裾**：地表反射や浅い散乱の波形の裾が氷層の時刻まで伸びている場合、M1 はそれも一緒に遅らせてしまう。
- **平均媒質の ε′**：1.871^ρ は ρ について下に凸なので、ゆらぎのある媒質の平均 ε′ は平均密度の値より約 0.16 % 大きい。走時のずれは 1 m で約 10 ps と小さい。
- **上端の走時のばらつき**：上の層のゆらぎで、上端の反射の走時がトレースごとに少しずつずれる。S は全トレースで同じ波形なので、このばらつきは合成側に入らない。

## 6. 合成データでの動作確認（コードの確認のみ）

テスト用の合成データ（均質な ε′ = 3 に密度ゆらぎを足したもので、Carrier のプロファイルではない）で動作を確認した。

- **S との一致**：このデータは解析モデルと違う媒質で作っているため、S とは走時も振幅も合わない。これは想定どおりで、実データで初めて意味を持つ。
- **時間伸縮**：実測の遅れは 0.55 ns で、モデル τ = 0.57 ns と一致した。
- **残差**：M1 の残差は T − R に比べて、氷層の中で −15.7 dB、下で −28.4 dB に下がった。

## 7. M2：反射のトレースごとのゆらぎ（2026-11-05 追加）

実データ（pore 10 vol%）の初回の結果から、次のことがわかった。

- トレースごとのピークの中央値は、S と 1 dB 以内で合っていた（上端 −0.5 dB、下端 −0.9 dB）。
- 一方、トレース平均の波形は、上端で −2.1 dB、下端で −5.0 dB と目減りしていた。
- 合成した B-scan の P_D は、上端で 0.07、下端で 0.12 だけ高く出た。

原因は、ランダムな上の層を通る伝搬で、反射の走時と振幅がトレースごとにゆらぐことだと考えた。そこで次のモデルを加えた。

  M2 : T ≈ W[R] + Σ_k a_jk S_k(t − δ_jk)

1. **当てはめ**：T − W[R] を、界面ごとのゲート（±EVENT_HW_NS）の中で a · S_k(t − δ) に当てはめる。
   - δ：相互相関が最大になる遅れ（±0.5 ns の範囲を 0.005 ns 刻みで探す）
   - a：その δ での最小 2 乗の振幅
2. **合成の 3 通り**：

| 版 | (a, δ) の与え方 | 意味 |
|---|---|---|
| measured | 測った値をトレースごとにそのまま使う | 当てはめで届く上限 |
| shuffled | トレースの間で入れ替える（10 回の平均） | 分布だけを保つ |
| parametric | a は対数正規（dB の平均・σ）、δ は正規分布（平均・σ）から引く（10 回の平均） | **マップ作成で実際に使う形** |

3. **確かめること**：
   - 平均波形の目減りの実測値が、a と δ からの予測 20 log10|mean(a·exp(−i2πf_c δ))| と合うか。合えば、目減りの原因が走時と振幅のゆらぎだと確かめられる。
   - parametric 版の P_D が、gprMax の P_D に（上端 0.80、下端 0.68）±0.05 程度で戻るか。

   **戻った場合**、マップに必要なのは「深さごとの (a の dB の平均・σ、δ の σ)」だけになる。これは上の層の伝搬で決まり、反射係数が小さければ濃度にはほぼよらないので、濃度ごとの計算は要らない。
   **戻らない場合**、走時と振幅以外の波形の歪みや、ゆらぎの空間的なつながりが効いている。

4. **予想**：平均波形の目減りから逆算すると、δ の σ は上端で約 0.09 ns、下端で約 0.14 ns。振幅の σ は ±2〜3 dB。

## 8. 実行

`bscan_detection.py` と同じフォルダに置き、`JSON_PATH` を確認してから実行する。

```
python bscan_superposition_check.py
```

- 入力の選び方、直達波の除去、トレースの範囲、基準の条件名は `bscan_detection.py` の設定をそのまま使う。
- 解析応答と時間伸縮には、基準と対象の両方の記録ファイル（`Ascan_level6_record.json`）が必要。
- 計算時間は数十秒程度（201 トレース）。

**版**：0.1（実装前）
**作成日**：2026-08-30

## 1. 目的とスコープ

### 1.1 目的

地表 tx/rx（at_tx、モノスタティック）で取得した A-scan から、**地下界面からの反射**を抽出し、次の 3 つを定量する。

1. **反射チャネル**：各界面の反射振幅 → 反射係数 R → 誘電率コントラスト → 氷量
2. **走時チャネル**：各界面の往復走時 → 層厚と層内の屈折率 → 氷量
3. **減衰チャネル**：界面間の反射振幅比 → 層の減衰係数 α

そのうえで、**3 つのうちどれが先に検出限界に達するか**を判定する。これが本研究の中心的な問いである。

### 1.2 スコープ外

| 項目 | 扱い |
|---|---|
| 埋設 rx（片道透過、A 系統） | **既存の `ascan_amplitude.py` / `ascan_spectrum.py` が担当**。本ツールは触らない |
| B-scan・測線走査 | Level 8。本ツールは単一トレースのみ |
| 多重反射を検出指標に使うこと | **採用しない**（後述 §1.3） |
| 逆解析（氷量の推定アルゴリズム） | 将来課題。本ツールは順方向の照合と検出限界の評価まで |

### 1.3 多重反射を指標にしない理由

Level 4 の埋設 rx データでは、氷層界面からの多重反射が周波数領域の干渉縞として現れ、振幅にして 0.07–0.34 dB p-p の変動を生んだ。これは減衰チャネルの信号（0.035 dB）より大きく、原理的には検出指標になり得る。

しかし**水平方向に一様な構造だから綺麗な縞になる**のであって、Level 6（界面ラフネス）・Level 7（ランダム媒質）では反射が方向を持って散乱し、コヒーレントな縞は崩れる。実機の地下構造で成立する保証がないため、**検出指標としては採用しない**。

ただし解析上は無視できないので、**理論との残差に現れる既知の項として扱い、図に注記する**（§6.4）。

## 2. 入力データ

### 2.1 必須

| データ | 内容 | 生成元 |
|---|---|---|
| **at_tx トレース** | 解析対象。tx と同位置の rx | `Level_N.in`（`RX_MODE = 'at_tx'`） |
| **参照計算** | 自由空間 1 m（`far_1m`） | 既存ツールと共通 |
| **氷なし参照トレース** | 同一設定で `ENABLE_ICE = False` の at_tx | `Level_4.in` |

### 2.2 氷なし参照トレースの 2 つの役割

**(a) ノイズフロアの測定**
媒質が完全に均質なので、地表反射より後の時間帯には何も返らないはず。そこに残る振幅が数値ノイズフロア（直達波の裾＋PML 反射＋格子分散）である。

判定基準（地表反射のピークに対する dB）：

| フロア | 判定 |
|---|---|
| < −70 dB | 0.5 vol% まで反射チャネルが使える |
| −60 〜 −70 dB | 1 vol% は可、0.5 vol% は厳しい。PML を 20 セルに増やすことを検討 |
| > −55 dB | **反射チャネルが成立しない。**先に対策が必要 |

**(b) 背景差分の参照**
氷ありトレースから引くと、地表反射・直達波の裾・PML 反射がまとめて消え、氷の寄与だけが残る。

> **注意**：背景差分は実機では使えない（月面では「氷がない場合の観測」が得られない）。**論文には差分あり（理論上限）と差分なし（現実的な条件）の両方を示すこと。**

差分が成立する条件は、2 本の計算が**氷の有無以外すべて同一**であること（dx・励振ファイル・時間窓・領域サイズ・PML セル数）。`Level_4.in` の `ENABLE_ICE` フラグで作れば自動的に満たされる。

### 2.3 入力パスの管理

既存ツールと同じ `out_file_paths.json` 形式を踏襲する。at_tx は既存の rx 階層に `at_tx` キーとして既に存在するため、**JSON の構造を変える必要はない**。

## 4. 物理モデル：往復反射の理論

### 4.1 記号

| 記号 | 意味 |
|---|---|
| h | tx/rx の地表面からの高さ（0.35 m） |
| n₀ = 1 | 真空の屈折率 |
| n_k | 層 k の屈折率 √(ε′_k(f)) |
| L_k | 層 k の厚さ |
| d_k | 界面 k の深さ |
| α_k | 層 k の減衰係数 |
| R_REF | 参照計算の距離（1 m） |

### 4.2 各イベントの理論振幅

界面 k からの反射のスペクトルは、参照 E_ref(f) に次を掛けたものとする。

```
E_k(f) = E_ref(f) × G_k × T_k × R_k × A_k × exp(-2*pi*i*f*t_k)
```

| 項 | 式 | 備考 |
|---|---|---|
| **G_k 幾何** | √(R_REF / r_eff,k) | 2D 遠方場。rx は真空中なので √n は付かない |
| **T_k 透過** | Π (往復透過係数) | 界面 k より浅い界面をすべて往復 |
| **R_k 反射** | (n_k − n_{k+1})/(n_k + n_{k+1}) | Ez は界面に接線 |
| **A_k 吸収** | exp(−2 Σ α_j L_j) | 界面 k までの往復 |
| **t_k 走時** | 2h/c + 2 Σ n_j L_j / c | 往復 |

### 4.3 見かけ源距離 r_eff（要検証）

近軸の屈折則「界面で r → r·(n_new/n_old)」を往復経路に適用すると、

```
r_eff,k = 2h + 2 * Σ_{j<=k} L_j / n_j
```

となる。**既存ツールの片道版 r_eff = n·h + d と同じ規則から導かれる**ため整合している。

**検証**：地表反射（k=0）では r_eff = 2h となり、Level 1 の実測（R = −0.268、t = 2.335 ns）と一致するはず。**これが実装の最初の合格条件**（§7.1）。

### 4.4 往復透過係数

界面を下向き・上向きに 1 回ずつ横切るときの積は

```
T_down * T_up = 4 n_1 n_2 / (n_1 + n_2)^2
```

- **地表面**（真空 ↔ レゴリス）：4×1.732/(2.732)² = **0.9282**（−0.65 dB）
- **氷層上面**（レゴリス ↔ 氷、10 vol%）：**0.99943**（−0.005 dB、ほぼ 1）

### 4.5 理論値（FeO+TiO2 = 7.5 wt%、氷層 1.0–2.0 m）

実装の照合に使う。

| 氷量 | R_top | 地表反射 | 氷上面 | 氷下面 |
|---|---|---|---|---|
| 0.5 vol% | −58.3 dB | 0.0 dB / 2.335 ns | **−53.4 dB** / 13.890 ns | −57.2 dB / 25.473 ns |
| 1 vol% | −52.3 dB | 〃 | **−47.4 dB** / 13.890 ns | −51.2 dB / 25.501 ns |
| 5 vol% | −38.4 dB | 〃 | **−33.5 dB** / 13.890 ns | −37.2 dB / 25.726 ns |
| 10 vol% | −32.5 dB | 〃 | **−27.5 dB** / 13.890 ns | −31.2 dB / 26.010 ns |

（dB はすべて地表反射のピーク振幅を基準）

> **重要**：氷上面の走時は氷量に依らず 13.890 ns で固定（上に氷がないため）。一方**下面の走時は氷量とともに遅れる**（25.473 → 26.010 ns）。この差が層内の屈折率、すなわち氷量を直接与える。

### 4.6 層内屈折率の逆算

上下面の往復走時差から、層内の屈折率が**幾何情報だけで**求まる。

```
n_layer = (t_bot - t_top) * c / (2 * L_layer)
```

理論値と完全に一致することを確認済み（10 vol% で 12.119 ns → n = 1.81665、真値 1.81665）。

**層厚 L が既知でなくても、n が既知なら L が求まる**という双対関係にある。実機では両方未知なので、この 1 式では決まらない。**将来 Level 8 の CMP（複数オフセット）で分離する**という道筋を README に残しておく。

### 4.7 減衰の逆算

上下面の反射振幅比から、層内の α が求まる。

```
alpha_layer = -ln( (A_bot / A_top) * (R_top / R_bot) * (G_top / G_bot) / T_top ) / (2 * L_layer)
```

R_top と R_bot は符号が逆で絶対値が等しいので比は 1、T_top ≈ 1 なので、実質は振幅比と幾何項の補正だけになる。

## 5. 機能要件

### F-1 トレース読み込みと前処理
- at_tx トレース、氷なし参照トレース、`far_1m` 参照計算を読み込む
- 時間刻みが異なる場合はリサンプル（既存 `resample_trace` を流用）
- **背景差分の ON/OFF をフラグで切り替えられること**

### F-2 ノイズフロアの測定
- 氷なし参照トレースについて、指定時間帯（既定 8–40 ns）の RMS 振幅を測る
- 地表反射のピークに対する dB で報告し、§2.2 の判定を出力する
- **このフロアを全図に水平線として重ね描きする**

### F-3 イベント検出
- 理論走時 t_k を中心に窓を張り、包絡ピークを探す
- 窓幅は既定 ±2 ns（パルス幅約 0.7 ns に対して十分。設定可能）
- 検出できなかった場合は「フロア以下」として記録し、**エラーにしない**
- 検出結果：到達時刻、包絡ピーク振幅、ピーク周辺の SNR

### F-4 反射チャネルの解析
- 各イベントの振幅から R_k を逆算（G・T・A で補正）
- 理論 R_k と比較し、残差を報告
- **氷量の掃引に対する R の理論曲線**を描き、測定点を載せる

### F-5 走時チャネルの解析
- 各イベントの到達時刻と理論値を比較
- 上下面の走時差から層内屈折率を逆算（§4.6）
- **氷なし理論との差**（= 検出信号）を明示する

### F-6 減衰チャネルの解析
- 時間ゲートで各イベントを切り出し、スペクトルを求める
- イベント間の LSR から層内 α(f) を逆算（§4.7）
- 理論 α と比較

### F-7 検出限界の判定
各チャネルについて、**信号 / ノイズフロア**を計算し表にする。既存ツールの合格判定と同じ思想で、チャネルごとに基準を持つ。

| チャネル | 信号の定義 | ノイズの定義 |
|---|---|---|
| 反射 | 界面反射のピーク振幅 | F-2 のフロア |
| 走時 | 氷なし理論からの走時差 | 数値分散由来の残差（Level 1 で較正） |
| 減衰 | 層内 α の氷なしからの差 | LSR 残差の RMS |

### F-8 差分あり/なしの並記
F-4〜F-7 を**背景差分あり・なしの両方で実行**し、同じ図に並べる。前者が理論上限、後者が実機で到達しうる条件。

## 7. 検証要件

実装は次の順に合格させる。**前の段が通るまで次に進まない。**

### 7.1 Level 1（無損失均質）

| 量 | 期待値 |
|---|---|
| 地表反射の走時 | **2.335 ns** |
| 地表反射の反射係数 | **R = −0.268** |
| 地表反射より後の振幅 | ノイズフロアのみ |

**これが通らなければ幾何項 r_eff = 2h が誤っている。**§4.3 の見かけ源距離の検証を兼ねる。

### 7.2 Level 3（均質・損失あり）

| 量 | 期待値 |
|---|---|
| 地表反射 | Level 1 と同じ（地表面より上は無損失） |
| 地表反射より後 | ノイズフロアのみ（界面がない） |

**F-2 のノイズフロア測定はこのデータで行う。**

### 7.3 Level 4（氷層あり、10 vol%）

§4.5 の表と照合する。許容差は次のとおり。

| 量 | 許容差 |
|---|---|
| 走時 | ±0.05 ns（数値分散の残差 0.025 ns の 2 倍） |
| 振幅 | ±0.5 dB（既存ツールと同じ基準） |
| 層内屈折率 | ±0.5% |

### 7.4 氷なし（`ENABLE_ICE = False`）

Level 3 と同一の結果になること。**背景差分の前提が満たされていることの確認。**

## 9. 既知の限界（実装時点で明記すること）

| 項目 | 内容 |
|---|---|
| 多重反射 | 理論に含めない。残差に現れる |
| 斜め入射 | モノスタティック（オフセット 0）前提。オフセットを付けるなら 20 cm までは垂直入射で近似可、それ以上は Fresnel 係数を斜め入射に直す必要 |
| 背景差分 | 実機では使えない。理論上限としてのみ扱う |
| 直達波の裾 | 2D 線源のグリーン関数は時間的に長い裾を引く。差分なしの場合はこれがフロアを決める可能性がある |
| 層厚と屈折率の縮退 | §4.6 のとおり 1 式では分離できない。Level 8 の CMP で分離する |
| ラフネス・ランダム性 | Level 6・7 では界面反射が散乱し、本ツールの前提（平坦・水平）が崩れる |

## 水氷の描像（pore / excess）

JSON のサブ階層キー（`pore_ice` / `excess_ice`）から**自動判定**する。

| 描像 | ε′ の混合 | ε″ | 減衰チャネル | 反射チャネル |
|---|---|---|---|---|
| `pore` 空隙充填 | ε_wet^(1/3) = ε_dry^(1/3) + v(ε_ice^(1/3) − 1) | 保存 | 弱い | **強い** |
| `excess` バルク置換 | ε_wet^(1/3) = (1−v)ε_dry^(1/3) + v·ε_ice^(1/3) | (1−v) 倍に希釈 | **強い** | 弱い |

10 vol%・7.5 wt% での比較。

| 描像 | ε′_ice | wt% | 界面反射 | α 変化 |
|---|---|---|---|---|
| pore | 3.300224 | 5.088 | **−32.5 dB** | −4.18% |
| excess | 3.014781 | 5.621 | −58.2 dB | **−9.73%** |

**wt% 換算も描像で変わる**（かさ密度の作られ方が違うため）ので、`ICE_SPEC='wt'` で指定する場合は特に注意すること。

描像キーが見つからない場合は**既定値に落とさずエラーで止まる**。誤った描像の理論曲線のまま解析が完走するのを防ぐため（組成・氷量の判定と同じ方針）。

出力先は JSON の階層をそのまま使うので、`pore_ice` / `excess_ice` で自動的に分かれる。

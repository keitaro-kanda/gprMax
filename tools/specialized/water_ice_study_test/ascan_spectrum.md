# ascan_spectrum.py

各深さの受信**スペクトル**を理論予測と比較し、減衰・分散に関わる量を段階的に検証するツール。

`ascan_amplitude.py` が「1 本の波形から 2 つのスカラー（振幅・到達時刻）」を取るのに対し、こちらは**周波数ごとに情報を取り出す**。入出力仕様は A-scan ツールを踏襲している。

---

## 1. なぜスペクトルを見るのか

水氷の検出は最終的に**ロスタンジェント tanδ の差**を測ることに帰着する。tanδ は周波数ごとの減衰量として現れるので、周波数分解した量を見なければ本質に届かない。

なお Level 2（σ 一定）では α が周波数に依存しないため、スペクトルの**形**は変わらず**水準だけ**が下がる。周波数依存が現れるのは Level 3（分散性媒質）からである。この違いを見分けられることが、スペクトル解析を用意する理由のひとつでもある。

さらに Level 1 では、スペクトル解析は A-scan 解析より**鋭い判定**ができる。理由は次節。

### 1.1 振幅と位相がきれいに分離する

Yee 格子の FDTD は**無損失媒質で厳密に非散逸**である。つまり伝達関数の絶対値は 1 で、数値分散は位相にしか現れない。したがって Level 1 では：

| 量 | 期待される振る舞い | 検出できるもの |
|---|---|---|
| **絶対LSR** ln\|E(f,d)/E_ref(f)\| | **周波数によらず完全に一定** | 幾何減衰・透過係数・PML 漏れ・理論実装 |
| **群遅延** τ_g(f) | 高周波ほど遅れる | 数値分散（そのもの） |

A-scan ツールの「振幅残差」と「到達時刻残差」は、この 2 つをスペクトル全体で平均した各 1 点に相当する。スペクトル解析はその周波数依存性を展開して見せる。

### 1.2 判定がゼロ基準になる

Level 1 の理論伝達関数は「実定数 × 線形位相」なので、|E| の**形**は参照とまったく同じになる。したがって

- 絶対LSR は完全に平坦（傾き = 0）
- f_c, σ_f, f_lo, f_hi は深さによらず一定

いずれも「理論値がゼロ／一定」なので、判定が曖昧にならない。

## 2. 解析項目の物理と定義

### 2.1 対数スペクトル比（LSR）

#### 絶対LSR

```
L_abs(f, d) = ln|E(f, d) / E_ref(f)|
            = ln T + ½·ln(n / r_eff(d)) − α(f)·d
```

第 1・2 項は周波数に依存しない定数（透過と幾何減衰）、第 3 項だけが周波数依存の吸収。

| レベル | 期待される形 |
|---|---|
| Level 1 | 周波数によらず一定 |
| Level 2（σ 一定） | **周波数によらず一定のまま、深さぶんだけ下がる** |
| Level 2（tanδ 一定・参考） | 傾き −π·tanδ·t₁ の直線（t₁ = n·d/c は片道走時） |

> **Level 2 で LSR が傾かないのが要点。** gprMax の `#material` が与えるのは導電率 σ であって tanδ ではなく、σ 一定なら α は帯域内でほぼ完全に一定になる（§2.4）。したがって絶対LSR は Level 1 と同じく水平のまま、吸収ぶんだけ下方にシフトする。**fig2(a) を見れば、どちらの損失モデルが効いているか一目で判別できる。**

Level 1 の期待値：

| 深さ [m] | r_eff | L_abs [dB] |
|---|---|---|
| 0.00 | 0.606 | +1.850 |
| 0.50 | 1.106 | −0.762 |
| 1.50 | 2.106 | −3.559 |
| 2.75 | 3.356 | −5.582 |

Level 2（σ = 0.0035 S/m）の期待値：

| 深さ [m] | 幾何 [dB] | 吸収 [dB] | L_abs 合計 [dB] | 帯域内の傾き |
|---|---|---|---|---|
| 0.00 | +1.850 | 0.000 | +1.850 | 0（水平） |
| 0.50 | −0.762 | −1.653 | −2.415 | 0（水平） |
| 1.50 | −3.559 | −4.959 | −8.518 | 0（水平） |
| 2.75 | −5.582 | −9.092 | −14.674 | 0（水平） |

参考：もし tanδ = 0.0155 一定なら傾きが出る（2.75 m で 0.5→2 GHz が −3.36 → −13.44 dB、差 −10.08 dB）。

#### 相対LSR

固定参照深さ d₀（既定 0.25 m）に対して取る。

```
L_rel(f, d) = ln|E(f, d) / E(f, d₀)|
            = ½·ln(r_eff(d₀) / r_eff(d)) − α(f)·(d − d₀)
```

**透過係数 T が相殺する**のが要点。波源スペクトルの絶対値も不要になる。

> **重要**：実機で測れるのは相対LSR だけである。絶対LSR は「波源スペクトルが既知」というシミュレーション固有の特権を使っている。Level 8 で「事前知識なしに水氷層を言い当てられるか」を問うとき、主役になるのは相対LSR のほう。

### 2.2 スペクトルモーメント

パワースペクトル P(f) = |E(f)|² に対して、

```
f_c   = ∫f·P df / ∫P df                       重心周波数
σ_f   = √( ∫(f−f_c)²·P df / ∫P df )           スペクトル幅
skew  = ∫(f−f_c)³·P df / ∫P df / σ_f³         歪度
```

**パワー基準（振幅ではなく |E|²）である点が重要。** これは次の恒等式と定義を揃えるため。

```
df_c/dt = −2π · tanδ · σ_f²
```

この式は減衰が周波数に線形（α ∝ f、すなわち tanδ 一定）であれば波源形状によらず厳密に成り立つ。導出は簡単で、P(f,t) = P₀(f)·exp(−2π·tanδ·f·t) を f_c の定義に入れて t で微分すると、右辺に分散が現れる。

> **Level 2（σ 一定）では α が周波数に依存しないので、この恒等式は使えない。** α が一定だと全周波数が同じだけ減衰するため、**スペクトルの形が変わらず f_c も σ_f も動かない**。f_c の深さ変化から tanδ を推定する手法が成立するのは、α が周波数依存を持つ場合（tanδ 一定、あるいは Level 3 の分散性媒質）に限られる。これは水氷検出の手法選択に直結する重要な制約である。

この恒等式が意味すること：

- **σ_f² を測らずに f_c の変化だけを見るのは、左辺だけ測って右辺を仮定していること**に等しい
- σ_f² が分かれば tanδ = −(df_c/dt)/(2π σ_f²) としてガウス仮定なしに tanδ が点推定できる
- **水氷の検出感度は σ_f² に比例する**。帯域を狭めると感度が落ちる

歪度は帯域端でのクリップ検出に使う。急に動いたらノイズフロアか帯域端に当たっている。

#### なぜ f_lo / f_hi に加えて σ_f が必要なのか

σ_f と f_lo/f_hi はどちらも「スペクトルの広がり」を表すように見えるが、役割はまったく違う。

**(1) σ_f² は感度係数そのもの**

上の恒等式の右辺に σ_f² が掛かっている。つまり σ_f² は「同じ tanδ に対して f_c がどれだけ動くか」を決める増幅率である。帯域を狭めて σ_f² が半分になれば、水氷の検出感度もそのまま半分になる。f_lo/f_hi はどの恒等式にも現れないので、この役割は担えない。

**(2) σ_f がないと tanδ に逆変換できない**

tanδ = −(df_c/dt)/(2π·σ_f²)。σ_f を測らずに f_c の変化だけを見るのは、恒等式の左辺だけ測って右辺を仮定しているのと同じである。

**(3) σ_f は積分量なので頑健**

σ_f はスペクトル全体をパワー重みで積分した**大域量**、f_lo/f_hi はしきい値を横切る**1 点**で決まる局所量である。帯域制限波源ではスペクトルが平坦なため、帯域内の傾きが 10 dB を超えるまで −10 dB 点はほとんど動けない。

減衰（tanδ = 0.0155）に対する応答を計算すると次のようになる。

| 深さ | 帯域内の傾き | f_lo(−10dB) | f_hi(−10dB) | f_c | σ_f |
|---|---|---|---|---|---|
| 0.00 m | 0 dB | 0.5571 | 1.9429 | 1.2500 | 0.3798 |
| 1.50 m | −5.50 dB | 0.5558 | 1.9211 | 1.1306 | 0.3686 |
| 2.75 m | −10.08 dB | 0.5548 | 1.8909 | 1.0407 | 0.3448 |
| 6.00 m | −21.99 dB | 0.5522 | 1.3281 | 0.8717 | 0.2597 |

深さ 2.75 m での変化率は **f_hi −2.7%、σ_f −9.2%、f_c −16.7%**、f_lo はほぼ不変（−0.4%）。f_hi は 2.75 m まで 1.9 GHz 付近に張り付いている。

**結論**：定量指標としての主役は **f_c と σ_f**。f_lo/f_hi の役割は「有効帯域が減衰で削られ始めたか」「ノイズフロアや帯域端にぶつかっていないか」を見る**診断**である。

### 2.3 上限・下限周波数

その深さのスペクトルの帯域内最大値に対して、**−3 / −10 / −20 dB** を横切る周波数。3 種類すべてを CSV に出し、プロットは代表値（既定 −10 dB）のみ。

- **f_hi** が減衰に最も敏感。深いしきい値ほど感度が高い可能性がある
- **f_lo** はほぼ不変のはず。動いたら異常
- 派生量として (f_hi − f_lo) と f_hi/f_lo も出力

ただし §2.2 のとおり、これらは**診断量**であって定量指標の主役ではない。帯域制限波源では傾きが 10 dB を超えるまで f_hi がほとんど動かないため、減衰の定量には f_c と σ_f を使うこと。

複数回横切る場合は最も外側（f_lo は最小、f_hi は最大）を採用する。

### 2.4 減衰係数 α(f) とロスタンジェント tanδ(f)

絶対LSR から幾何項を引いて深さで割る。

```
α(f) = −[ L_abs(f, d) − ln(T·√(n/r_eff(d))) ] / d
```

相対LSR からも同様に求める（実機で可能な版）。

```
α(f) = −[ L_rel(f, d) − ½·ln(r_eff(d₀)/r_eff(d)) ] / (d − d₀)
```

ロスタンジェントへの変換は低損失極限の関係 α ≈ π f n tanδ / c を逆に解いて

```
tanδ(f) = α(f) · c / (π · f · n)
```

**判定基準は「全深さの α(f) が 1 本の曲線に重なるか（collapse するか）」。** 重ならなければ深さ依存の何かが混入している。

#### Level 2 の理論曲線：σ 一定なら α は水平、tanδ は 1/f

gprMax の `#material: er sigma mr sigma*` が与えるのは**導電率 σ** である。導電損失は等価的に ε″ = σ/(ω ε₀) なので

```
tanδ = ε″ / ε′ = σ / (ω ε₀ ε_r)   ∝ 1/f
```

となり、**σ 一定なら tanδ は 1/f で落ち、α はほぼ完全に一定になる。**

コードは α を近似せず厳密式で計算している。

```
α = (ω/c) · √(ε_r/2) · √( √(1 + tan²δ) − 1 )
```

低損失極限では次に一致する。

| モデル | 低損失極限の α | α の周波数依存 | tanδ の周波数依存 |
|---|---|---|---|
| `conductivity`（既定） | σ·η₀ / (2n) | **なし** | ∝ 1/f |
| `tan_delta`（参考） | π·f·n·tanδ / c | ∝ f | なし |

σ = 0.0035 S/m での数値（プロファイル計算の 0 vol% ice / 1.25 GHz の値）：

| f [GHz] | tanδ | α [Np/m] | 2.75 m 片道 |
|---|---|---|---|
| 0.50 | 0.04194 | 0.3806 | −9.090 dB |
| 1.25 | **0.01678** | 0.3806 | −9.092 dB |
| 2.00 | 0.01049 | 0.3806 | −9.092 dB |

fig3 の理論曲線（赤破線）はレベルに応じて自動的に切り替わる。**Level 1 では α = 0 の水平線、Level 2 では上表の α(f)（ほぼ水平）と tanδ(f)（1/f で落ちる曲線）が描かれる。**

> **なぜ tanδ 一定にできないのか。** tanδ を一定にするには ε″ を周波数によらず一定（= σ ∝ f）にする必要があり、gprMax では `#add_dispersion_debye` による多極 Debye でしか実現できない。さらに Kramers-Kronig の関係から、ε″ を帯域内で一定にすると ε′ も必ず分散する。つまり「tanδ 一定かつ ε′ 非分散」は厳密には物理的に実現できず、**σ 一定こそが「非分散な損失媒質」の自己整合な姿**である。tanδ 一定は Level 3 の領域になる。

#### 1/d 増幅に注意

α は「LSR 残差 ÷ d」なので、**同じ大きさの残差でも浅いほど拡大される**。

| 深さ | 0.03 dB の残差に対する α [1/m] | d=2.75 に対する倍率 |
|---|---|---|
| 0.25 m | 0.0138 | **11.0 倍** |
| 1.00 m | 0.0035 | 2.8 倍 |
| 2.75 m | 0.0013 | 1.0 倍 |

tanδ に換算して目標信号と比べると、実用上の意味がはっきりする（f = 1.25 GHz、LSR 残差を 0.03–0.05 dB とした場合）。

| 深さ | 見かけの tanδ | 水氷 1 vol% の信号（1.55×10⁻⁴）との比 |
|---|---|---|
| 0.25 m | 1.0×10⁻³ | **6.5 倍（信号より大きい）** |
| 1.00 m | 1.8×10⁻⁴ | 1.1 倍 |
| 2.00 m | 7.6×10⁻⁵ | 0.5 倍 |
| 2.75 m | 5.2×10⁻⁵ | 0.3 倍 |

**α・tanδ の推定には長いベースラインが必須**で、1 m 未満では系統誤差が目標信号を上回る。これは LSR 法に必要な最小深さ区間を決める根拠になる。

なお d = 0（at_surface）は伝搬距離ゼロで α が未定義なので NaN として除外される。

### 2.5 群遅延

参照に対する位相の周波数微分。

```
φ(f, d) = unwrap( arg[ E(f, d) / E_ref(f) ] )
τ_g(f, d) = −(1/2π)·dφ/df + r_ref/c
```

理論値は t_arr(d) = h/c + n·d/c で、Level 1・2 では周波数によらず一定。

**この量が数値分散を直接測る。** 振幅は非散逸性により影響を受けないので、数値分散は群遅延にのみ現れる。深さ 2.75 m での予測値（dx = 5 mm）：

| f [GHz] | 0.5 | 1.0 | 1.25 | 1.5 | 2.0 |
|---|---|---|---|---|---|
| 厳密値からの遅れ [ns] | 0.014 | 0.056 | 0.087 | 0.126 | **0.227** |

帯域内で 16 倍変化する。A-scan ツールの包絡ピーク遅れ（2.75 m で 0.092 ns）は、この曲線をスペクトル全体で平均した 1 点に相当する。

Level 3 で 2 極 Debye を入れると、これに**物理分散**が重なる。両者は同じ「高周波ほど遅い」正常分散なので縮退しやすく、Level 1 で数値分散の大きさを確定しておくことが不可欠になる。

微分は数値的に敏感なので、位相をアンラップしてから `np.gradient` で求めている。

## 3. マスクとノイズフロア

### 3.1 解析帯域

```python
BAND_GHZ = (0.5, 2.0)      # LUPEX GPR の動作帯域（決め打ち）
```

モーメントと上限下限周波数はこの帯域で計算する（マスクは適用しない）。

> **gaussiandot を解析する場合の注意**：gaussiandot@1.25 GHz は 2 GHz より上に全パワーの 27.5% を持つため、この帯域で切ると裾が落ちる。理論側も同一帯域・同一関数なので**検証としては自己整合**するが、この σ_f² は恒等式に入れる「真の σ_f²」ではない。感度見積もりに使うのは帯域制限波源の値のみとすること。

### 3.2 LSR 系の 2 段マスク

帯域制限波源は Tukey テーパーのため帯域端で振幅が落ちる（0.5 GHz と 2.0 GHz ちょうどで **−25 dB**）。LSR は ln|E/E_ref| なので、分母が小さい帯域端では数値的に不安定になる。

```python
MASK_REF_FLOOR_DB = -20.0   # |E_ref| が帯域内最大からこれ以上落ちる周波数を除外
MASK_SNR_MIN_DB   = 20.0    # 各トレースのノイズフロアからこれ以上上にある周波数のみ
```

- **第 1 マスク**：−20 dB で切ると **0.511–1.989 GHz、帯域の 98.6% が残る**
- **第 2 マスク**：Level 2 以降で高周波が減衰して埋もれたときに自動的に効く

マスクは **LSR・α(f)・tanδ(f)・群遅延**に適用する。モーメントには適用しない（帯域端の寄与はほぼゼロで、マスクすると理論との定義がずれるため）。

### 3.3 ノイズフロアの推定

```python
NOISE_BAND_GHZ = (3.0, 5.0)
```

波源にはこの帯域の成分がほぼない（>3 GHz で 10⁻⁵ %）ため、そこに残っている |E| の RMS は**数値ノイズと PML 漏れ**である。これを各トレースのノイズフロアとする。

有効帯域の上下端を CSV に記録するので、「f_hi が下がったのは減衰か、ノイズに埋もれたか」を切り分けられる。

## 4. 時間ゲート

```python
GATE_ENABLED = False        # 既定：無効
```

**既定でゲートをかけない理由**：埋設 rx には直達波が 1 つしかないため、トレース全体を FFT してよい。これにより、以前の STFT 解析で σ_f² を 25–40% 膨らませていた**窓関数のバイアスが原理的に発生しない**。窓の校正も不要になる。

Level 6 以降で散乱体や層界面からの反射が入ったらゲートが必要になる。そのときは Level 1–5 で確立した「ゲートなしの真値」と比較して窓バイアスを校正する。

**有効にする場合の必須ルール**：参照・実測・理論の 3 つすべてに、**同じ幅・同じ形状**のゲートを、それぞれの包絡ピークを中心にかけること。片方だけにかけると比較が成立しない。ゲート中心は A-scan ツールと同じく `t_arr + t_src_delay` から決める。

## 5. 理論モデル

A-scan ツールと**同一の伝達関数**を使う。ただし IFFT には戻さず、周波数領域のまま扱う。

```
E_theory(f, d) = E_ref(f) · T · √(n/r_eff(d)) · √r_ref · exp(−α(f)·d) · exp(−2πi·f·(t_arr(d) − r_ref/c))
```

詳細は `README_ascan_amplitude.md` §2–3 を参照。吸収項 exp(−α(f)·d) の中身（`LEVEL2_LOSS_MODEL`、`LEVEL2_SIGMA`）は §2.4 を参照。

レベルごとに掛かる項は `LEVEL_EFFECTS` 辞書で決まる。

```python
LEVEL_EFFECTS = {
    'Level_1': ['geom', 'surface_T'],                        # 実装済み
    'Level_2': ['geom', 'surface_T', 'absorb_const'],        # 実装済み
    'Level_3': ['geom', 'surface_T', 'absorb_debye'],        # 未実装
    'Level_4': ['geom', 'surface_T', 'absorb_debye', 'density_profile'],  # 未実装
}
```

参照計算は別ドメインの計算で周波数グリッドが異なりうるため、複素スペクトルを実部・虚部それぞれ線形内挿して共通グリッドに揃えている。

**at_tx はこのツールでは解析対象外**（理論モデルが透過経路のみを定義しているため）。

```
$ python ascan_spectrum.py
レベル: Level_1 (候補が 1 つのため自動選択)
```

#### fig1(b) エラーバーの読み方

## 7. 合格基準

| 項目 | 定数 | 基準 |
|---|---|---|
| 絶対LSR の水準 | `LSR_TOL_DB = 0.5` | 各深さの帯域平均が理論と ±0.5 dB |
| 絶対LSR の平坦度 | `LSR_FLATNESS_TOL_DB = 0.3` | 平均を除いた後の帯域内 peak-to-peak |
| f_c の深さ依存 | `FC_TOL_MHZ = 10.0` | Level 1 では全深さで一定 |
| 群遅延 | `TAUG_TOL_FRAC = 0.01` | 走時の 1% 以内 |
| ノイズフロア | `NOISE_FLOOR_DB = -60.0` | 帯域内信号の −60 dB 以下 |

**Level 1 の本命は「絶対LSR の平坦度」と「モーメントの深さ非依存性」。** どちらも理論的にゼロになるべき量なので判定が曖昧にならない。

### 「許容できるか」の判断のしかた

許容値との比較だけでなく、**目標信号と比べる**のが本質的である。

| 量 | Level 1 の系統誤差 | 水氷 1 vol% の信号 | 水氷 10 vol% の信号 |
|---|---|---|---|
| f_c | 約 0.5 MHz | 4.4 MHz | 42 MHz |

f_c の系統誤差は 1 vol%（= 0.5 wt%、ミッション目標）の信号の約 1/9 である。この比較ができて初めて「許容できる」と言える。

## 8. 結果の読み方

### 8.1 fig1・fig2：スペクトル形状が保たれているか

Level 1 の伝達関数は「実定数 × 線形位相」なので、**スペクトルの形は保たれ振幅だけが下がる**のが正しい姿。fig1(a) で全深さの曲線が平行に下がり、fig2(a) の絶対LSR が水平なら設計どおり。

fig1(b) では、全深さのエラーバーが（水平方向に）ほぼ同じ位置に揃うのが Level 1 の期待される姿である。バーが深さとともに縮んでいたら、それは減衰が効き始めた証拠になる。

### 8.2 fig3 と fig4 で深さ依存性が逆転する理由

一見矛盾するが、誤差の生まれ方が違うため。

| 図 | 深さ依存 | 理由 |
|---|---|---|
| **fig3（α）** | 浅いほど悪い | 一定の振幅誤差を **d で割る** → 1/d 増幅 |
| **fig4（群遅延）** | 深いほど大きい | 数値分散が**伝搬距離に比例して蓄積** |

fig4 は誤差ではなく、数値分散を正しく測れているということ。

さらに fig3 では、**LSR 残差そのものも浅いほど大きい**ため二重に効く。理由は理論モデルの遠方場近似で、kr_eff が浅いほど小さいから。

| 深さ | r_eff | kr @0.5 GHz | kr @2 GHz |
|---|---|---|---|
| 0.00 m | 0.606 | 11.0 | 44.0 |
| 2.75 m | 3.356 | 60.9 | 243.7 |

fig2(b) と fig2(d) で残差が低周波側に持ち上がるのも同じ理由（低周波ほど kr が小さい）。

### 8.3 残差の正体

FDTD は無損失媒質で振幅誤差を作れないので、残差の出どころは**理論モデル側**である。2 つに分解できる。

- **深さに依存しない成分**：透過係数 T の離散化誤差（実測 +0.97% = +0.084 dB）、波源校正
- **深さに依存する成分**：遠方場近似 1/√r_eff と見かけの源距離 r_eff = n·h + d の近似

絶対LSR には両方が乗り、相対LSR では前者が相殺する。CSV から両者を引き算すればこの分解が実際にできる。

## 9. 既知の限界

| 項目 | 備考 |
|---|---|
| 実装レベル | Level 1・Level 2 を実装。Level 3–4（`absorb_debye`, `density_profile`）は `NotImplementedError` |
| Level 2 の損失モデル | σ 一定のみ物理的に自己整合。tanδ 一定は参考用（§2.4） |
| 遠方場近似 | §8.3 のとおり残差の主因。理論モデルの精度限界 |
| α の短ベースライン | §2.4 のとおり d < 1 m では系統誤差が目標信号を上回る |
| at_tx | 対象外（理論モデルが透過経路のみ） |
| 群遅延の平滑 | 現状は平滑なし。ノイズが問題になったら再検討 |
| f_lo/f_hi の鈍感さ | 帯域制限波源では傾きが 10 dB を超えるまでほとんど動かない（§2.2） |
| 3D への移行 | 幾何項が 1/√r → 1/r に変わる。`transfer_geom` の修正が必要 |

## 10. Level 2 の実装状況と Level 3 以降への拡張

### Level 2（実装済み）

```python
LEVEL2_LOSS_MODEL = 'conductivity'   # gprMax の #material に対応（既定）
LEVEL2_SIGMA = 0.0035                # [S/m] #material の第 2 引数と一致させること
LEVEL2_TAN_DELTA = 0.0155            # 'tan_delta' モデルのときのみ使う
```

`level2_alpha()` / `level2_tandelta()` / `transfer_absorb()` が実装され、`LEVEL_EFFECTS['Level_2']` で有効になる。実行時と `run_info.txt` に媒質設定が記録される。

```
Level_2 の媒質: loss model = conductivity, sigma = 0.0035 S/m
  (tan_delta = 0.01678 @1.25 GHz, alpha = 0.3806 Np/m, alpha は帯域内でほぼ一定)
```

> **`LEVEL2_SIGMA` は `.in` ファイルの `#material` の第 2 引数と必ず一致させること。** ここがずれると絶対LSR に一定のオフセットが出る。

### Level 3 以降

Level 3（2 極 Debye）では α(f) が非線形になり、n も n(f) になるため、`transfer_phase` の走時も周波数依存にする必要がある。位相速度と群速度が分かれる点にも注意。

**レベル依存は `LEVEL_EFFECTS` 辞書と `transfer_*()` 関数群にのみ現れ、他の場所に `if level == ...` を書かない**というルールを守ること。

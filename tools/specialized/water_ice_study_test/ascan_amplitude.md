# ascan_amplitude.py

A-scan の**振幅と到達時刻**を理論予測と比較し、各 Level で理論からの乖離が生じる複雑性を特定するツール。

---

## 1. このツールが答える問い

複雑性のはしご（Level 0–8）において、各段で次を判定する。

> シミュレーションは、その段で入れた物理だけで説明できているか？

Level 1（均質・無損失・非分散）なら、受信波形の振幅を決めるのは**幾何減衰と地表面透過だけ**のはずである。実測がそれと一致すれば合格、ずれれば「入れていない何か」が効いている。

---

## 2. 物理的背景

### 2.1 なぜ rx を地中に埋めるのか

送受信同位置（at_tx）の測定は往復反射だが、Level 1–5 の主対象は **rx を地中に置いた片道透過**である。理由は 3 つ。

1. 反射体が不要で、反射係数の周波数依存が混入しない
2. 波源セル自身の特異な近傍場（自己場）と混ざらない
3. 各深さが独立した 1 本の直達波になり、時間ゲートが不要になる

### 2.2 2D 線波源の幾何減衰

gprMax の 2D モードでは `#hertzian_dipole` は不変方向に伸びた**線電流源**として働く。2 次元の自由空間 Green 関数は Hankel 関数 H₀⁽²⁾(kr) で、遠方場 (kr ≫ 1) の漸近形は

```
H₀⁽²⁾(kr) ≈ √(2/(π k r)) · exp(−i(kr − π/4))
```

したがって振幅は **1/√r** で減衰する。3D の 1/r とは異なる点に注意。

### 2.3 見かけの源距離（屈折による波面曲率の変換）

送信機は地上 h = 0.35 m にあり、rx は地中の深さ d にある。波は界面で屈折するため、レゴリス側から見た「源までの距離」は h ではない。

法線入射での見かけ距離（apparent depth）の関係から、

```
r_eff(d) = n·h + d          n = √ε_r
```

Level 1（ε_r = 3）では **r_eff = 0.606 + d**。空気中の 0.35 m が、屈折によってレゴリス側からは 0.606 m に見える。密な媒質に入ると光線が法線側に曲がり、ビームの発散が緩くなるため、源が遠くにあるように見える。

振幅は 1/√(r_eff) に比例する。**全深さ（0–2.75 m）での振幅変化はわずか 7.4 dB** しかない。

### 2.4 地表面透過係数

Ez は水平界面に対して**接線成分**なので界面で連続である。したがって

```
空気側:     E_air = (1 + R)·E_inc
レゴリス側: E_reg = T·E_inc
かつ 1 + R = T
```

法線入射で

```
T = 2 / (1 + n)          Level 1 では 0.7321
R = (1 − n) / (1 + n)    Level 1 では −0.268
```

**T は埋設 rx 全点に共通の定数**であり、深さ依存性には一切効かない。効くのは絶対振幅の議論と、at_surface / 自由空間参照との比較のときだけである。

### 2.5 走時

法線入射なので単純に

```
t_arr(d) = h/c + n·d/c
```

Level 3 以降で分散性を入れると、位相速度と群速度が分かれるためこの式は近似になる。

## 3. 数学的枠組み：周波数領域フォワードモデル

### 3.1 なぜレベルごとに式を書き分けないのか

Level ごとに「振幅の解析式」を書くのではなく、**周波数領域の伝達関数を効果の積で構成し、逆 FFT して波形を合成する**。

```
E_theory(f, d) = E_ref(f) · H_level(f, d)
                        ↓ IFFT
                    理論波形 → measure() → 特徴量
```

利点は 4 つ。

1. **レベル差が「掛ける項の有無」だけで表現できる**（`LEVEL_EFFECTS` 辞書 1 個で切り替わる）
2. **理論と実測に同一の測定関数を適用できる** → 定義ズレが原理的に起きない
3. **2D 特有の波尾が自動的に含まれる**。2D の線波源は Huygens の原理を満たさず、Green 関数 1/(2π√(t²−r²/v²)) に由来する長い尾を引く。振幅をスケールしただけの波形と比較すると必ずズレる
4. **gprMax の絶対スケーリング（1/dl 等）や波源の微分次数を知らなくてよい**

### 3.2 伝達関数の全体像

参照計算（自由空間、tx-rx 距離 r_ref = 1 m）との比を取る形で定義する。

```
                          ①        ②              ③        ④              ⑤
H_level(f, d) =  T  ×  √(n / r_eff(d))  ×  √r_ref  ×  exp(−α(f)·d)  ×  exp(−2πi·f·(t_arr(d) − r_ref/c))
```

| # | 項 | 名前 | 深さ依存 | 周波数依存 | Level 1 での値 | 実装 |
|---|---|---|---|---|---|---|
| ① | T | 地表面透過係数 | なし | なし | 0.7321 | `transfer_surface_T` |
| ② | √(n / r_eff(d)) | **幾何減衰** | あり | なし | 0.526〜1.237 | `transfer_geom` |
| ③ | √r_ref | 参照距離への規格化 | なし | なし | 1（r_ref=1 m） | `transfer_geom` に同梱 |
| ④ | exp(−α(f)·d) | 媒質の吸収 | あり | あり | **1（未実装）** | `transfer_absorb` |
| ⑤ | exp(−2πif(t_arr−r_ref/c)) | 走時位相 | あり | あり | — | `transfer_phase` |

> **重要**：上の式は**全レベル共通の一般形**である。実際にどの項が掛かるかは `LEVEL_EFFECTS` 辞書で決まる。
>
> ```python
> LEVEL_EFFECTS = {
>     'Level_1': ['geom', 'surface_T'],                        # ← 位相項は常に追加される
>     'Level_2': ['geom', 'surface_T', 'absorb_const'],   # ← 実装済み
>     'Level_3': ['geom', 'surface_T', 'absorb_tandelta'],  # ← 実装済み（ε″ 一定）
>     'Level_3b': ['geom', 'surface_T', 'absorb_debye'],     # ← 実装済み（高Ti、分散性）
>     'Level_4': ['geom', 'surface_T', 'absorb_tandelta', 'ice_layer'],  # ← 実装済み（水氷層）
>     'Level_5': ['geom', 'surface_T', 'absorb_tandelta', 'ice_layer',
>                 'density_profile'],                            # ← 未実装
> }
> ```
>
> **Level 1 で効いているのは ①②③⑤ の 4 項**、**Level 2 ではこれに ④ の吸収項が加わる**。**Level 3 では ④ が ε″ 一定（≒ tanδ 一定）の吸収になる**（ε′ の変化が 0.4% と小さいため ①②⑤ は暫定的に Level 1・2 と同じ扱い。厳密には ε′(f) を入れるべきで、これが修正項目 A-3）。**Level 3b では ④ が 2 極 Debye になり、n(f) を通じて ①②⑤ も周波数依存になる**。**Level 4 では ④ が層ごとの積分 exp(−∫α dz) になり、氷層界面の透過係数 ⑥ が加わる**。Level 5（`density_profile`）はまだ `NotImplementedError` を投げる。

> **修正項目 A-3 は適用済み。** Level 3・4 の ε′ は実装した 2 極 Debye の値（KK 由来の 0.43% の変化を含む）を使う。したがって ①②⑤ も n(f) を通じて周波数依存になる。`LEVEL3_EPS_REAL_MODE = 'ideal'` にすると従来どおり定数に戻せる。

### 3.2.1 ①②③ の導出：幾何減衰はどこにあるか

式を見ると「幾何減衰」という名前の項が見当たらないが、**②と③がそれ**である。参照との比を取った結果、Hankel 関数の形が消えているために分かりにくくなっている。導出を追うと見える。

S(f) を波源スペクトル、2D 遠方場の伝搬因子を G ∝ 1/√(k·r)·e^(−ikr) とする（§2.2）。

**参照計算**（すべて空気中、距離 r_ref）：

```
E_ref(f) = S(f) · A / √(k_air · r_ref) · exp(−i·k_air·r_ref)
```

**対象**（空気中 h → 界面で透過 → レゴリス中 d）：

| 段階 | 振幅 |
|---|---|
| 界面に到達 | S(f) · A / √(k_air · h) |
| 透過 | × T |
| レゴリス中を d 進む | × √(n·h / r_eff) |

3 段目が肝心である。**レゴリス側から見ると、波面は半径 n·h の面として界面から始まり**（§2.3 の見かけの源距離）、深さ d だけ進むと半径 n·h + d = r_eff になる。2D では振幅が 1/√(半径) なので、比は √(n·h / r_eff) となる。

**比を取る**：

```
H = E / E_ref
  = T · √(k_air·r_ref) / √(k_air·h) · √(n·h / r_eff) · exp(−2πif·(t_arr − r_ref/c))
  = T · √(r_ref / h) · √(n·h / r_eff) · exp(...)
  = T · √(n · r_ref / r_eff) · exp(...)
  = T · √(n / r_eff) · √r_ref · exp(...)
```

この過程で 3 つのことが起きている。

1. **k_air が相殺する** → 幾何項が周波数に依存しない実数になる。**だから最終式に Hankel 関数が現れない**。r_eff を Hankel 関数の引数 kr に代入するわけではない
2. **√h も相殺する** → √(r_ref/h) と √(n·h/r_eff) の中で h が消える
3. **分子に n が残る** → √(1/h)·√(n·h) = √n から出てくる。参照は空気中、対象はレゴリス中という**媒質の乗り換え**の帳尻を合わせている項

③の √r_ref は参照距離への規格化で、r_ref = 1 m なら値は 1 である。式に明示してあるのは、参照距離を変えたときに正しく効くようにするため。

### 3.2.2 ④ 吸収項（Level 2 以降）と Level 3 の分散

> **Level 3 では①②④⑤のすべてが周波数依存になる。** ε′ が周波数依存になると
> 屈折率 n(f) = √(ε′(f)) が周波数依存になり、n を含む項すべて
> ——幾何項 √(n/r_eff)、透過係数 2/(1+n)、走時位相——が f 依存を持つ。
> 「Level 3 は吸収項を差し替えるだけ」ではない点に注意。
>
> コードでは `refractive_index(f, level)` が一元的に n を返す。
> Level 1・2 では定数配列、Level 3 では √(ε′(f)) になる。


```
exp(−α(f)·d)          α は減衰係数 [Np/m]、d は片道の伝搬距離
```

Level 1 は無損失なので α = 0、この項は 1 になる。**媒質の損失を表す唯一の項**である。

#### gprMax が与えるのは「導電率一定」であって「tanδ 一定」ではない

ここは Level 2 で最も間違えやすい点なので、独立させて書く。

`#material: er sigma mr sigma*` の第 2 引数は**導電率 σ** である。導電損失は等価的に ε″ = σ/(ω ε₀) なので

```
tanδ = ε″ / ε′ = σ / (ω ε₀ ε_r)   ∝ 1/f
```

**σ が一定なら tanδ は 1/f で落ちる。** 逆に tanδ を一定にしたければ ε″ を周波数によらず一定（= σ ∝ f）にする必要があり、gprMax では `#add_dispersion_debye` による多極 Debye でしか実現できない。さらに Kramers-Kronig の関係から、ε″ を帯域内で一定にすると ε′ も必ず分散する。

つまり **「tanδ 一定かつ ε′ 非分散」は厳密には物理的に実現できない**。したがって役割分担は次のようになる。

| | 損失モデル | α の周波数依存 | gprMax での実現 |
|---|---|---|---|
| **Level 2**（非分散） | σ 一定 | ほぼ一定 | `#material: 3 0.0035 1 0` |
| **Level 3**（分散性） | Debye | 物性に従う | `#add_dispersion_debye` |

**σ 一定こそが「非分散な損失媒質」の物理的に自己整合な姿**であり、tanδ 一定は Level 3 の領域である。

#### 実装

```python
LEVEL2_LOSS_MODEL = 'conductivity'   # gprMax の #material に対応（既定）
LEVEL2_SIGMA = 0.0035                # [S/m] #material の第 2 引数と一致させる
LEVEL2_TAN_DELTA = 0.0155            # 'tan_delta' モデルのときのみ使う
```

α は近似せず厳密式で計算する。

```
α = (ω/c) · √(ε_r/2) · √( √(1 + tan²δ) − 1 )
```

低損失極限では次に一致する。

| モデル | 低損失極限の α | 周波数依存 |
|---|---|---|
| conductivity（Level 2） | σ·η₀ / (2n) | **なし** |
| tan_delta（参考） | π·f·n·tanδ / c | f に比例 |
| **2 極 Debye（Level 3）** | 下記の厳密式 | **α ∝ f^1.38 程度** |

σ = 0.0035 S/m では厳密式と近似の差は 0.02% 以下だが、近似を持ち込まないため厳密式で実装している。

#### σ = 0.0035 S/m での数値

プロファイル計算の **0 vol% ice / 1.25 GHz** の値を採用している。

| f [GHz] | tanδ | α [Np/m] | 2.75 m 片道 |
|---|---|---|---|
| 0.50 | 0.04194 | 0.3806 | −9.090 dB |
| 1.25 | **0.01678** | 0.3806 | −9.092 dB |
| 2.00 | 0.01049 | 0.3806 | −9.092 dB |

**α は帯域内でほぼ完全に一定**なので、絶対LSR は Level 1 と同じく**周波数に対して水平のまま、深さに応じて下がる**。tanδ 一定なら傾く（0.5→2 GHz で 2.75 m なら −3.36 → −13.44 dB）ので、signature がまったく違う。この差は fig2(a) で一目で判別できる。

参考として、深さ 2.75 m の理論値は

```
−14.674 dB = −5.582 (幾何減衰) + −9.092 (吸収)
```

と分解される。

### 3.2.3 ⑤ 走時位相項

```
t_arr(d) = h/c + n·d/c
exp(−2πi·f·(t_arr(d) − r_ref/c))
```

**r_ref/c を引いているのが要点**である。E_ref にはすでに参照計算の 1 m 伝搬ぶんの遅延が含まれているので、そのまま t_arr を掛けると遅延を二重に計上してしまう。差分だけを掛ける。

この項は振幅に一切影響しない（絶対値 1）。効くのは波形の時間位置と形だけである。

### 3.3 参照計算が必須な理由

`_reference.far_1m`（自由空間、rx を tx から 1 m 離した計算）が無いとこのツールは動かない。この 1 本から次の 3 つを実測で得ている。

1. **実効波源スペクトル E_ref(f)** — 波源の微分次数も 2D Green 関数の寄与も全部込み
2. **時刻原点** — 波源自身の内部遅延（後述）
3. **dB の基準振幅**

**tx と同位置の計算では代用できない。** 波源セルの Ez は放射波ではなく特異な近傍場（kr ≪ 1 で H₀⁽²⁾ が対数発散する領域）であり、遠方場とは周波数特性がまったく違う。1 m なら 1.25 GHz で kr = 26 と十分な遠方場になる。

### 3.4 波源の内部遅延の自動校正

波源波形はそれ自身が遅延を持つ。

- `gaussiandot @1.25 GHz` → χ = 1/f = **0.8 ns**
- 帯域制限 excitation file → T_CENTER = **5.0 ns**

理論波形のピークは `t_arr + この遅延` に現れる。したがって探索窓の中心にこの遅延を加えないと、窓がパルスを外して**全深さで一定の残差**が出る（実際に発生した不具合）。

コードは参照波形の包絡ピークから実測する。

```python
t_src_delay = measure(E_ref, ..., t_predicted=None)['t_peak'] − r_ref/c
```

**波源を変えても定数の書き換えが不要**になる設計。

## 4. 測定関数 `measure()`

実測波形と理論波形に**まったく同じ関数**を適用する。これがツールの中核ルール。

### 4.1 手順

1. **Hilbert 変換の絶対値**で包絡を作る
2. 探索窓 `[t_center ± SEARCH_HALFWIDTH_NS]` 内で包絡の最大値を探す
3. ピーク時刻を**放物線内挿**でサブサンプル精度に上げる（dt = 11.79 ps に対し必要）
4. 後方窓（40–50 ns）の包絡 RMS をノイズフロアとする

`t_predicted = None` を渡すと全区間から探す。参照波形のようにパルスが 1 つだけの場合に使う。

### 4.2 探索窓の中心の決め方

```
理論波形 → t_arr + t_src_delay
実測波形 → 理論波形のピーク位置
```

`measure()` 自体は共通のまま、中心の与え方だけを変えている。窓の端でピークが見つかったら警告を出す（真のピークが窓外にある可能性が高いため）。

### 4.3 なぜ包絡ピークなのか

生波形のピークは搬送波の位相に依存して跳ぶが、包絡ピークは滑らかで、群速度で伝わる量に対応する。ただし**波源の内部遅延を含む**ため、絶対値ではなく実測と理論の残差で評価する。

## 5. at_tx（反射測定）の扱い

at_tx は片道透過ではなく往復反射なので別式になる。

```
理論振幅 = R · √(r_ref / 2h)      = −0.320
理論到達 = 2h / c                  = 2.33 ns
```

**自己場の除去が必須。** 波源セルの Ez は反射より 40–60 dB 大きいため、そのままでは反射が埋もれる。同一ジオメトリの自由空間計算（`_reference.at_tx`）を差し引く。

```
E_reflect = E_at_tx − E_at_tx_freespace
```

Level 1 は無損失・線形なのでこの差分は数学的に厳密である。参照が JSON に無ければ at_tx はスキップされる。

---

## 6. 透過係数チェック

`_reference.at_surface`（レゴリスなしで rx を地表面位置に置いた計算）があれば、

```
T_meas = amp(at_surface, レゴリスあり) / amp(at_surface, 自由空間)
```

が理論値 2/(1+n) = 0.7321 と一致するかを判定する（許容 ±1%）。Level 1 で取れる最もクリーンな検証項目の 1 つ。

## 7. 使い方

### 7.1 パス JSON

```json
{
  "_reference": {
    "gaussiandot": { "far_1m": "...", "at_tx": "...", "at_surface": "..." },
    "excitation_waveform": {
      "dx_0005":  { "far_1m": "...", "at_tx": "...", "at_surface": "..." },
      "dx_00025": { "far_1m": "...", "at_tx": "...", "at_surface": "..." }
    }
  },
  "Level_1": {
    "gaussiandot": { "at_surface": "...", "depth_025": "..." },
    "excitation_waveform": {
      "dx_0005":  { "at_surface": "...", "depth_025": "..." },
      "dx_00025": { "at_surface": "...", "depth_025": "..." }
    }
  }
}
```

- `_` 始まりのキーはレベル／rx として扱わない
- **階層の深さは枝ごとに違ってよい**。値が文字列になった時点で rx の階層とみなし、そこまで番号選択で降りる
- `_reference` は Level 側より浅くてよい。選択したキー列を順に辿り、該当階層が無ければそこで止まる
- `_reference` はトップレベルにも各レベル内にも置ける（レベル内が優先）
- rx キー名 `depth_XXX` の数値部が深さ [cm]

> **dx ごとに参照計算を用意すること。** `#hertzian_dipole` は電流密度 J = I·dl/(Δx Δy Δz) とセル寸法で正規化されるため、2D では波源の絶対振幅が dx に依存する。dx が違う参照を使うと絶対振幅が定数倍ずれる（dx 2 倍で約 6 dB）。時間格子の違いはリサンプルで吸収できるが、振幅の正規化までは吸収できない。dt 不一致を検出したら警告が出る。

### Level 3 の媒質モデル（ε″ 一定）

> **用語**：Level 3 を「非分散」と呼ばない。ε″ ≠ 0 の媒質は Kramers-Kronig 則により ε′ が必ず対数的に変化するため、厳密な意味で非分散な損失媒質は存在しない。Level 3 の正しい記述は「**ε″ が帯域内で一定、ε′ は KK により 0.43% 変化**」である。ε′ が厳密に定数なのは Level 1（無損失）と Level 2（σ 一定。DC 導電率の KK 対応項は ε′ に寄与しない）だけ。

Boivin+2022 の実測により、月南極（イルメナイト <1 wt%）は**帯域内で ε″ がほぼ一定**であることが確認された。

| 試料 | 分散 | 出典 |
|---|---|---|
| 純バイトウナイト | **なし**（P/L/S/X の 16 倍の帯域で ε′=3.29, ε″=0.006 が完全一定） | Table 7 |
| 1, 5 wt% ilm | **なし**（有意な分散を検出できずフィット不能と報告） | 本文 |
| 10–20 wt% ilm | あり（Cole-Cole） | Table 4 |

したがって **Level 3 は tanδ 一定 → α ∝ f** をベースラインとする。

```python
LEVEL3_EPS_R = 3.0                # 全組成共通。基準周波数は帯域の幾何平均 1.0 GHz
LEVEL3_RHO   = 1.753647           # eps' = 1.871^rho = 3.0 の逆算値
LEVEL3_CARRIER_EPS_BASE = 1.871   # Fig. 9.53 図中: eps' = 1.871^rho
LEVEL3_CARRIER_TAND_A   = 0.027   # Fig. 9.53 図中の 3 次元回帰
LEVEL3_CARRIER_TAND_B   = 0.273
LEVEL3_CARRIER_TAND_C   = 3.058
LEVEL3_COMPOSITIONS = {'feo5': 5.0, 'feo7p5': 7.5, 'feo10': 10.0, 'feo20': 20.0}
```

#### 経験式の出典と選択理由

出典は **Carrier, Olhoeft & Mendell (1991), Lunar Sourcebook Ch.9, Fig. 9.53 (SOILS)** の図中式。

```
eps'      = 1.871^rho
tan_delta = 10^(0.027*(%TiO2 + %FeO) + 0.273*rho - 3.058)
```

Fig. 9.53（土壌試料のみの回帰）を選ぶ理由は 3 つ。

1. 本研究の対象はレゴリス（土壌）であり、岩石片を含む Fig. 9.52 (ALL DATA) や Fig. 9.54 (450 MHz DATA) より母集団が適切
2. tanδ の周波数依存を無視する立場をとる以上、**周波数で切ったサブセット（Fig. 9.54 = 450 MHz）を選ぶのは仮定と矛盾する**。選ぶべき軸は周波数ではなく試料種別
3. 土壌データは ρ ≈ 1.0–2.1 に分布し、ρ = 1.753647 はその中心付近にある（内挿であって外挿でない）

> **ε′ の式と tanδ の式は同一図・同一サブセットから取ること。**片方だけ他図の式に差し替えると自己整合が崩れる。

| 図 | サブセット | ε′ の基底 | tanδ の 3 次元回帰 |
|---|---|---|---|
| 9.52 | 全試料 | 1.919 | 10^(0.038·S + 0.312ρ − 3.260) |
| 9.53 | **土壌のみ（採用）** | **1.871** | **10^(0.027·S + 0.273ρ − 3.058)** |
| 9.54 | 450 MHz のみ | 1.843 | 10^(0.033·S + 0.231ρ − 3.061) → Level 3b で使用 |
| 9.55 | Apollo 15–17 | 1.908 | 10^(0.028·S + 0.167ρ − 2.975) |

4 式の振れ幅は 5–10 wt% で採用値の 0.80–1.09 倍、N_eff で 0.9–1.5 倍。**経験式の選択による不確かさは、帯域制限（6.3 倍）や組成の見直し（6.6 倍）より 1 桁小さい。**

> **参考**：ρ = 1.753647 は Carrier の密度プロファイル ρ(z) = 1.92(z+12.2)/(z+18) [z: cm] の**深さ約 49 cm** に相当する。「深さ 50 cm 付近のレゴリスを一様に敷き詰めた媒質」と解釈できる。

**ε′ が組成に依らないので、全組成で ρ・走時・幾何減衰が共通**になり、違いは吸収だけという比較しやすい構成になる。

> **損失の振幅は Carrier 式から取る。** Boivin のバイトウナイト値（tanδ=0.002）を使わないのは、バイトウナイトが純長石で Fe をほぼ含まないのに対し、実際の南極レゴリスは olivine/pyroxene 由来の FeO を 5–6 wt% 含むため。**Boivin から採るのは「ε″ が周波数に依らない」という形状情報だけ**にする。

| FeO+TiO2 | tanδ | α@0.5 | α@1.25 | α@2.0 | 2.75 m @1.25 GHz |
|---|---|---|---|---|---|
| 5 wt% | 0.003595 | 0.0326 | 0.0816 | 0.1305 | −1.95 dB |
| **7.5 wt%** | **0.004200** | 0.0381 | 0.0953 | 0.1525 | **−2.28 dB** |
| 10 wt% | 0.004906 | 0.0445 | 0.1113 | 0.1781 | −2.66 dB |
| 20 wt%（参考） | 0.009136 | 0.0829 | 0.2073 | 0.3317 | −4.95 dB |

（旧版 Fig. 9.54 の値との比: 5 wt% ×1.088 / 7.5 wt% ×1.051 / 10 wt% ×1.015 / 20 wt% ×0.884）

**α 帯域内比は全組成で 4.000**（α ∝ f）。

#### gprMax では多極 Debye が必要

`#material: er sigma` は ε″ = σ/(ωε₀) ∝ 1/f を与えるので、**tanδ 一定は作れない**（それは Level 2）。tanδ を一定にするには ε″ を帯域内で平坦にする必要があり、Debye 1 極の ε″ はピークを持つため複数極で平坦化する。

極は **2 極・最大平坦の解析解**を使う（数値最適化は使わない）。1 極 Debye の ε″ を対数周波数 u = ln(ωτ) で書くと sech 関数になるので、u = ±s に等強度で置いて重ねると

```
eps''(u)/De = (1/2)[ sech(u-s) + sech(u+s) ]
```

となり、u = 0 で最大平坦になる条件が **s = arcsinh(1) = ln(1+√2)**、すなわち緩和時間比 (1+√2)² = 5.8284 と閉形式で決まる。対称中心を帯域の幾何平均 f₀ = √(f_lo·f_hi) = 1.0 GHz に取ると

```
tau1 = 1/(2*pi*f0*(1+sqrt2)),  tau2 = (1+sqrt2)/(2*pi*f0)
De   = sqrt(2) * eps''_target        （各極）
eps_inf = eps_r - De                 （f0 で eps' = eps_r）
```

の 4 行ですべて決まる（`1/(1+(w0·tau1)²) + 1/(1+(w0·tau2)²) = 1` が厳密に成り立つため）。

| 解 | ε″ 誤差 RMS | 帯域端 | α 誤差 p-p | 最小 τ/Δt |
|---|---|---|---|---|
| **解析解（最大平坦・採用）** | **0.89%** | **−2.44%** | **2.56%** | **11.2** |
| 数値解（等リップル） | 0.19% | ±0.25% | 0.96% | 10.4 |

数値解のほうが精度は高いが、論文で式を一行で書けなくなり、ソルバの初期値・収束条件が結果に効くため採用しない。**解析解の誤差が振幅に与える影響は深さ 2.75 m で約 −0.06 dB** であり、合否判定幅 ±0.5 dB に対して十分小さい。

ただし **fig3(a) の α(f) は帯域端で理論線から約 −2.5% ずれる**。これは既知の設計誤差であり、解析コードがそれを検出できていることの確認にもなるので、隠さずに図示して説明する。

### 数値分散について

Yee 格子の FDTD は**無損失媒質で厳密に非散逸**である。したがって数値分散は位相（到達時刻）にのみ現れ、振幅には効かない。振幅の低下として観測されるものは、高周波成分が遅れてパルスが広がった結果の**ピーク値低下**であり、エネルギーは失われていない（後方の尾に再配分されている）。

「数値拡散」ではなく「数値分散」である点に注意。

## Level 4（水氷層）の理論

> **本ツールの適用範囲**：地表 tx ＋ 埋設 rx（片道透過、A 系統）専用。
> at_tx（地表 tx/rx で地下反射を見る B 系統）の解析は別ツールで扱う。
> したがってここでの Level 4 の理論は「**氷層を透過して深さ d に届く波**」の
> 振幅・走時であり、氷層からの反射そのものは扱わない。

### はしごの順序変更

### 混合則（LLL 増分形）

水氷はレゴリス粒子を置き換えるのではなく、**粒子間の空隙（真空）に凝結する**（Takekura et al. 2025, Remote Sensing 17, 1050 の Fig. 2 と同じ描像）。LLL 混合則 ε^(1/3) = Σ v_i ε_i^(1/3) を 3 相（粒子・真空・氷）に適用し、乾燥時との差を取ると粒子の項が相殺して

```
eps'_wet^(1/3) = eps'_dry^(1/3) + v_ice * (eps_ice^(1/3) - 1)
eps''_wet      = eps''_dry + v_ice * eps_ice * tan_delta_ice
```

となる。**この形なら粒子密度も粒子誘電率も式に現れず**、乾燥側に Carrier の経験式をそのまま使えるので経験式との接続が保たれる。

損失は粒子にあり氷はほぼ無損失なので ε″ は保存する。**虚部に混合則を適用してはならない**（損失源が増えていないのに減衰が増えるという非物理的な結果になる）。

> 混合則の選択（LLL か対数混合か）による差は 1 vol% の界面反射で約 1.5 dB。「氷が空隙を埋める」か「レゴリスを置き換える」かの差（約 26 dB）に比べて桁違いに小さい。**重要なのは規則ではなく描像。**

### 伝達関数への追加項

経路が層構造になるので、3 つの項が層ごとの版に差し替わり、1 項が追加される。

| 項 | 単層版 | 層構造版 | 差し替えの理由 |
|---|---|---|---|
| ① 幾何 | `transfer_geom` | `transfer_geom_layered` | 見かけ源距離を界面で r → r·n_new/n_old と更新 |
| ④ 吸収 | `transfer_absorb_tandelta` | `transfer_absorb_layered` | exp(−Σ α_i L_i) |
| ⑤ 位相 | `transfer_phase` | `transfer_phase_layered` | t = h/c + Σ n_i L_i/c |
| **⑥ 氷層界面透過** | — | `transfer_ice_T` | 横切った界面の T の積 |

⑥ は Ez が界面に接線なので T = 2n₁/(n₁+n₂)。上面（レゴリス→氷）と下面（氷→レゴリス）を横切った分だけ掛ける。

- **rx が氷層の内部**：上面の 1 回分だけ効く。10 vol% で **−0.21 dB**
- **rx が氷層より深い**：両方掛かり積は 4n₁n₂/(n₁+n₂)² ≈ 1。10 vol% で **−0.005 dB**

多重反射は R² のオーダー（10 vol% で −64 dB）なので無視する。

### 検算：氷 0 vol% で Level 3 に一致するか

`LEVEL4_ICE_VOL_PCT = 0.0` にすると Level 4 の伝達関数は Level 3 と厳密に一致する（実測の相対差 5.7×10⁻¹⁴、浮動小数の丸めのみ）。層構造版の実装が単層版の正しい一般化になっていることの確認になる。

## 水氷の描像（pore / excess）

JSON のサブ階層キー（`pore_ice` / `excess_ice`）から**自動判定**する。設定は `configure_from_kind()` が組成・氷量とまとめて行う。

| 描像 | ε′ の混合 | ε″ | 減衰チャネル | 反射チャネル |
|---|---|---|---|---|
| `pore` 空隙充填（吸着水） | ε_wet^(1/3) = ε_dry^(1/3) + v(ε_ice^(1/3) − 1) | 保存 | 弱い | **強い** |
| `excess` バルク置換（過剰氷） | ε_wet^(1/3) = (1−v)ε_dry^(1/3) + v·ε_ice^(1/3) | (1−v) 倍に希釈 | **強い** | 弱い |

10 vol%・7.5 wt%・深さ 2.75 m での違い。

| 描像 | 界面反射 | 振幅差 \|H₄/H₃\| | 走時差 |
|---|---|---|---|
| pore | **−32.5 dB** | +0.0904 dB | **+0.2826 ns** |
| excess | −58.2 dB | +0.0837 dB | +0.0153 ns |

**振幅差はほぼ同じだが走時差が 18 倍違う。**excess では ε′ がほとんど変わらないためで、埋設 rx の解析では**走時が描像の判別に効く**ことになる。

**wt% 換算も描像で変わる**（かさ密度の作られ方が違うため）ので、`ICE_SPEC='wt'` を使う場合は注意すること。描像キーが見つからない場合は**既定値に落とさずエラーで止まる**。

# make_excitation_file.py

LUPEX GPR の動作帯域 (0.5–2.0 GHz) を模擬する gprMax 用 `#excitation_file` を生成するスクリプト。

---

## 1. なぜ必要か

gprMax の `#waveform` で `gaussiandot 1 1.25e9` を指定すると、次の 2 つの問題が起きる。

**問題1：スペクトルのピークが指定周波数からずれる**

`#waveform` の第2引数は「中心周波数」だが、これは Gaussian の幅を決めるパラメータであって、実際に放射される電界のスペクトルのピークではない。`hertzian_dipole` は電流源であり、電流から放射電界に至る過程でスペクトルの形が変わるため、1.25 GHz を指定してもピークはそこに来ない。

**問題2：帯域が広く伸び、数値分散を招く**

Gaussian 系の波形はスペクトルの裾が長い。実測ベースの推定では、gaussiandot@1.25 GHz の放射スペクトルは**全パワーの 27.5% が 2 GHz より上**にあった。この高周波成分は FDTD 格子で十分に解像されず（dx = 5 mm、ε_r = 3 のとき 2 GHz で PPW = 17.3、4 GHz で 8.7）、数値分散によって遅れる。その結果パルスが広がり、包絡ピークが下がる。

Level 1 の検証では、この効果が深さ 2.75 m で **到達時刻 +0.198 ns、振幅 −1.15 dB** の系統誤差として現れた。Level 2 で測ろうとしている吸収が同じ距離で −8.4 dB であることを考えると、**測定対象の約 14% が数値誤差**という比率になる。

**帯域制限による改善（dx = 5 mm のまま、深さ 2.75 m）**

| 波源 | Δt | 走時比 | ΔA |
|---|---|---|---|
| gaussiandot@1.25 GHz | 0.198 ns | 1.16% | **−1.149 dB** |
| 帯域制限 0.5–2.0 GHz | 0.092 ns | 0.54% | **−0.030 dB** |

振幅残差が 38 倍改善する。**dx を細かくする必要がなくなる**ため、とくに B-scan の計算コストで効いてくる（dx 半減は 2D で計算量 8 倍）。

同時に、実機である LUPEX GPR の帯域を正しく模擬することにもなる。

## 2. 電流と放射電界の関係

### 2.1 gprMax の `#hertzian_dipole` は電流源

gprMax のドキュメントより、`#hertzian_dipole` は電流密度源である。

```
J_s = I · Δl / (Δx Δy Δz)
```

また 2D モードでは「不変方向の線電流源」として働く。したがって `#excitation_file` に書き込むのは**電流 I(t) [A]** であって、電界ではない。

### 2.2 伝達関数

電流から遠方場の放射電界までに、2 つの効果がかかる。

**(a) 時間微分（電流 → 電界）：×(i·2πf)**

振幅は f に比例、位相は +90°。

**(b) 2D Green 関数の遠方場：×f^(−1/2)**

2 次元の自由空間 Green 関数は Hankel 関数 H₀⁽²⁾(kr) で、遠方場 (kr ≫ 1) の漸近形は

```
H₀⁽²⁾(kr) ≈ √(2/(π k r)) · exp(−i(kr − π/4))
```

振幅は 1/√(kr) ∝ f^(−1/2)、位相には定数項 +45° が含まれる。

**(a) と (b) を合わせると：**

2D 線波源の厳密解は

```
E_z = −(ω μ / 4) · I · H₀⁽²⁾(kr)
```

なので、遠方場漸近を代入して

```
E(f) = I(f) · A · f^P · exp(i·φ)     P = 1 − 0.5 = 0.5,  φ = 180° + 45° = 225° ≡ −135°
```

A は任意の実定数（距離とグリッドスケーリングに依存）。

> **注意**：3D の「電流 → 電界は時間微分だから +90°」という直感は 2D では成り立たない。
> 上式では ω が実係数として現れ、代わりに前係数の −1 が 180° を与える
> （Green 関数 G = 1/(4j)·H₀⁽²⁾ の 1/(4j) が −90° を担う）。

コード上の対応：

| 記号 | 定数 | 既定値 |
|---|---|---|
| P | `EXPONENT_P` | 0.5 |
| φ | `PHASE_CONST_DEG` | −135.0 |

φ は周波数によらない定数なので**振幅スペクトルには影響しない**。予測「波形」の形だけを決める。

### 2.3 実測での検証

P と φ は理論値だが、既存の自由空間計算から実測できる。

```
python make_excitation_file.py --calibrate /path/to/free_space_test/result/Ascan.out
```

このモードは、参照 A-scan が `#waveform: gaussiandot 1 1.25e9` で計算されたものと仮定し、gprMax の定義

```
gaussiandot(t) = −2ζ(t−χ)·exp(−ζ(t−χ)²)     χ = 1/f₀,  ζ = 2π²f₀²
```

から入力電流 I(t) を再構成する。そのうえで

```
G(f) = E_ref(f) / I(f)
```

を求め、|G| をべき乗則 log|G| = P·log f + const でフィットして P を、1 m の伝搬遅延 exp(+i2πf/c) を除いた残りの偏角の平均から φ を得る。

実測値が理論値から外れていたら、対応する定数を書き換えること。

## 3. 電流波形の作成ロジック

`design_current()` が以下の 6 段階で電流波形を組み立てる。

### 手順1：目標スペクトル W(f) を作る

Tukey 窓で [F_LO, F_HI] を切り出す。`TUKEY_ALPHA` がテーパー幅の割合で、0 なら矩形、1 なら Hann。

```
W(f) = Tukey(f; F_LO, F_HI, TUKEY_ALPHA)
```

これは**放射電界に対する目標**であって、電流に対する目標ではない。

### 手順2：f^(−P) で事前補償する

E(f) = I(f)·f^P としたいので、逆算して

```
I(f) = W(f) / f^P
```

帯域外では W = 0 なので f → 0 の発散は起きない。この 1 行が「電流と電界のスペクトル形状が違う」問題への対処そのもので、診断図のパネル (c) で青（電流）が帯域内で右下がりになっているのがこの補償の姿である。

### 手順3：ゼロ位相にして t_center へ置く

```
I(f) ← I(f) · exp(−i·2πf·T_CENTER)
```

ゼロ位相にすることで、時間領域では T_CENTER を中心とする**左右対称のパルス**になる。

### 手順4：逆 FFT

`np.fft.irfft` で時間波形にする。

### 手順5：時間窓をかける（重要）

帯域制限された波形はサイドローブの減衰が遅く、そのままだと t = 0 で振幅が残る。実装当初は **t = 0 で −27 dB** が残っており、これは gprMax にとって不連続な立ち上がりであり、広帯域の過渡応答を注入してしまう。

そこで `[T_CENTER ± T_HALF_WIDTH]` の外で厳密に 0 になる Tukey 時間窓をかける。

```
I(t) ← I(t) · Tukey_time(t; T_CENTER, T_HALF_WIDTH, TIME_TAPER)
```

**時間窓は帯域を広げる**（時間と周波数はフーリエ対で、片方を狭めれば他方は広がる）。この代償で帯域外漏れは −292 dB から −40 dB に増えるが、後述のとおり実害はない。

### 手順6：振幅を正規化

ピーク電流を `PEAK_CURRENT`（既定 1.0 A）にそろえる。従来の `#waveform: gaussiandot 1 ...` と同じスケールになる。

なお、解析側 (`ascan_amplitude.py`) は E_ref(f) を実測から校正するため、絶対振幅は結果に影響しない。

## 4. 放射電界の予測ロジック

診断用に、放射電界のスペクトルと波形を予測する。

### スペクトル

```python
e_spec = np.fft.rfft(current) * radiation_transfer(f)
radiation_transfer(f) = f^P · exp(i·φ)
```

複素数のまま保持する。振幅だけなら `np.abs(e_spec)`。

### 波形

```python
e_wave = np.fft.irfft(e_spec)
```

伝達関数に伝搬遅延を含めていないので、予測波形も T_CENTER を中心に現れる。

**この波形は「遠方場での放射電界の形」であり、絶対値には意味がない。**

### 近傍場と比較してはいけない

パネル (b) は**遠方場**の予測である。rx を tx と同じ位置に置いた計算（自己場）と比較しても一致しない。

波源セルでは kr ≈ 0.03–0.1 と深い近傍場にあり、

```
H₀⁽²⁾(kr) ≈ 1 − i(2/π)[ln(kr/2) + γ]
```

の対数項が効く。この項は振幅も偏角も周波数依存で（|H₀⁽²⁾| は 0.5 GHz で 2.6、2 GHz で 1.8）、遠方場漸近 √(2/πkr)·exp(−i(kr−π/4)) とはまったく異なる周波数特性を持つ。その結果、自己場では

- スペクトルが平坦にならず、2 GHz 側へ約 +2 dB 傾く
- 主トラフの左右の正ピークの大小が遠方場と逆転する（左/右 ≈ 0.46 対 遠方場 1.70）

という違いが出る。**これは励振ファイルの不備ではなく、近傍場の性質そのもの。地下へ伝搬していくのは遠方場なので実害はない。**

比較は必ず **rx を 1 m 以上離した計算**（`ref_freespace_1m`、rx を (1.5, 2.35) に配置）で行うこと。1.25 GHz で kr = 26 と十分な遠方場になる。 位相定数 φ が波形の形を決めるため、φ が実測とずれていれば形も変わる。決定的な確認は、新しい波源で自由空間計算を回して実測波形と比べること。

なお **φ は振幅スペクトルに影響しないので、解析パイプラインの結果は φ の値によらない。**

## 5. 出力

指定したディレクトリに 2 つのファイルを書き出す。

### `lupex_src.txt`（gprMax excitation file）

```
time lupex_src
0.000000e+00 0.000000000e+00
5.000000e-12 1.234567890e-05
...
```

- 1 行目：識別子。先頭列は `time` 固定
- 2 行目以降：時刻 [s] と電流 [A]

**`time` 列を入れているのが要点。** gprMax は `scipy.interpolate.interp1d` でモデルの Δt に補間するため、**dx（したがって Δt）を変えても同じファイルを使い回せる**。収束テストで dx = 2.5 mm を試すときも再生成不要。

`T_WINDOW`（既定 50 ns）まで全時間をカバーしているので、補間の範囲外エラーも起きない。

### `lupex_src_diagnostics.png`（診断図、4 パネル）

| パネル | 内容 | 見るべき点 |
|---|---|---|
| (a) | 電流波形 I(t)（ファイルに書き出されるもの） | 両端で厳密に 0 になっているか |
| (b) | 放射電界の予測波形 E(t) と包絡 | パルス幅、リンギングの減衰 |
| (c) | スペクトル（線形）：I(f) と E(f) | E(f) が帯域内で平坦か、I(f) が右下がりか |
| (d) | 放射スペクトル（dB） | 帯域端の切れ、帯域外の漏れレベル |

## 6. 診断出力の読み方

```
--- 設計結果 ---
  帯域            : 0.50 - 2.00 GHz (Tukey alpha=0.2)
  事前補償の指数 P: 0.50  (E ∝ I * f^P)
  放射スペクトル  : -3 dB 帯域 0.614 - 1.887 GHz / 重心 1.250 GHz
  sigma_f^2       : 0.1432 GHz^2  (感度 ∝ この値)
  放射波形の包絡幅: 0.890 ns (FWHM) -> 深さ分解能 約 0.077 m (eps_r=3)
  帯域外漏れ      : 9.180e-05  (-40.4 dB)
  時間窓端の残留   : -600.0 dB (ピーク比)
```

**−3 dB 帯域と重心**：平坦設計では単一の「ピーク周波数」が定義できないため、この 2 つで報告する。重心が帯域中心 (1.250 GHz) に一致していれば設計どおり。

**sigma_f²**：パワースペクトルの分散。水氷検出感度に直結する量で、

```
df_c/dt = −2π · tanδ · σ_f²
```

の右辺に現れる。**この値が大きいほど水氷を検出しやすい。**

**包絡幅と深さ分解能**：帯域幅 B に対しおよそ 1/B。深さ分解能は v·FWHM/2（ε_r = 3 で v = 0.173 m/ns）。

**帯域外漏れ**：[0.4, 2.2] GHz の外にあるパワーの割合。−40 dB あたりが目安。数値分散に効くのは 3 GHz より上の成分で、そこは 10⁻⁵ % 程度しかない。

**時間窓端の残留**：t = 0 と t = 2·T_CENTER における振幅（ピーク比）。時間窓によって厳密に 0 になっているはず。

## 7. パラメータの調整指針

ファイル先頭の `[EDIT HERE]` 節。

| 定数 | 既定値 | 意味と調整指針 |
|---|---|---|
| `F_LO`, `F_HI` | 0.5, 2.0 GHz | LUPEX GPR の動作帯域。通常は変更しない |
| `TUKEY_ALPHA` | 0.2 | **感度とのトレードオフあり（下記）** |
| `EXPONENT_P` | 0.5 | `--calibrate` の実測値に合わせる |
| `PHASE_CONST_DEG` | −135.0 | 同上。予測波形の形だけに影響 |
| `T_CENTER` | 5.0 ns | パルス中心時刻 |
| `T_HALF_WIDTH` | 4.5 ns | 時間窓の半幅。帯域外漏れが大きければ小さく |
| `TIME_TAPER` | 0.3 | 時間窓のテーパー。大きいほど帯域外漏れが減る |
| `T_WINDOW` | 50 ns | モデルの `#time_window` 以上にすること |
| `DT_FILE` | 5 ps | ファイル内の時間刻み。モデルの Δt と一致不要 |
| `PEAK_CURRENT` | 1.0 A | ピーク電流 |

### TUKEY_ALPHA のトレードオフ

| α | σ_f² | 感度への影響 |
|---|---|---|
| 0.0（矩形） | 0.188 | 基準 |
| 0.1 | 約 0.17 | −10% 程度 |
| **0.2（既定）** | **0.143** | **−24%** |
| 0.5 | 0.093 | −50% |

数値分散への効果は α によらずほぼ同じ（深さ 2.75 m で Δt が 0.090 ns 対 0.092 ns）。したがって**感度を優先するなら α を下げる余地がある**。時間窓（手順5）で不連続の問題は既に解決しているため、α を下げても実害は帯域端がなまることだけ。

## 8. 使い方

### 手順1：P と φ を検証（初回のみ）

```
python make_excitation_file.py --calibrate /Volumes/.../free_space_test/result/Ascan.out
```

実測 P が 0.5 付近、実測位相が −135° 付近なら理論どおり。ずれていたら `EXPONENT_P` / `PHASE_CONST_DEG` を書き換える。

### 手順2：波形を生成

```
python make_excitation_file.py
出力ディレクトリを入力してください [Enter で "."] > /Volumes/.../Excitation_waveform_files
```

非対話で実行する場合：

```
python make_excitation_file.py --outdir /path/to/dir [--no-plot]
```

### 手順3：`.in` ファイルで使う

```
#excitation_file: /Volumes/.../Excitation_waveform_files/lupex_src.txt
#hertzian_dipole: z 1.5 3.35 0 lupex_src
```

**`#waveform` の行は削除すること。**

## 9. 波源を変えたあとにやること

### 必須：自由空間参照計算の取り直し

`ascan_amplitude.py` は E_ref(f) を自由空間 A-scan から実測して校正する設計なので、**解析コードの修正は不要**。ただし参照計算そのものは新しい波源で回し直す必要がある。

- `free_space_test`（1 m 離れた rx）
- `free_space_at_tx`（at_tx の自己場除去用、作成済みなら）
- `free_space_surface`（透過係数チェック用、作成済みなら）

### 推奨：予測波形との照合

新しい `free_space_test` の A-scan と、診断図パネル (b) の予測波形を重ねて比較する。一致すれば P と φ の妥当性が確認できる。ずれていれば定数を実測値に合わせる。

### 推奨：Level 1 の再検証

同じ Level 1 の計算を新しい波源で回し直し、`ascan_amplitude.py` の残差が ±0.5 dB 以内に収まることを確認する。予測では深さ 2.75 m で −0.030 dB になるはず。

### 注意：検出感度の見積もりが変わる

帯域制限により σ_f² が現行の実効値 0.362 から 0.143 GHz²（α = 0.2）へ下がる。感度は σ_f² に比例するので、**水氷検出感度は現行見積もりの約 4 割**になる。

これは劣化ではなく、**これまでが実機性能を過大評価していた**という補正である。2 GHz より上の 27.5% のパワーは実機には存在しないため。

感度シートの前提値 σ_f² = 0.20 に近づけたい場合は `TUKEY_ALPHA` を 0.1 程度まで下げる（§7 参照）。

## 10. 既知の制約

- **遠方場近似**：2.2 節の f^(−1/2) は Hankel 関数の主要項のみ。kr ≳ 10 で誤差 1% 程度。1.25 GHz、1 m の参照距離で kr = 26 なので問題ない。低周波側（0.5 GHz、kr = 10.5）でやや悪化する
- **予測波形は目安**：位相定数 φ が理論値の場合の形。決定的な確認は自由空間計算との照合（§9）
- **P は 2D 固有**：3D に移行する際は Green 関数が 1/r になるため P = 1.0 に変わる
- **NumPy 互換**：`np.trapz`（1.x）と `np.trapezoid`（2.x）の両方に対応済み

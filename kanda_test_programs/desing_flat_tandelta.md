# design_flat_tandelta.py

帯域内で **tanδ を一定に保つ多極 Debye パラメータ**を設計し、その妥当性を図で説明するツール。

---

## 1. 何のためのツールか

月南極のレゴリス（イルメナイト <1 wt%）は**非分散**である。すなわち帯域内で

```
ε′  = 一定
ε″  = 一定       →       tanδ = ε″/ε′ = 一定
```

これを gprMax で実現したいが、**gprMax の材料モデルでは直接指定できない**。

```
#material: ε_r σ μ_r σ*    →    ε″ = σ/(ω ε₀) ∝ 1/f
```

σ 一定では tanδ が 1/f で落ちてしまう（これが Level 2）。gprMax は Debye / Lorentz / Drude しか持たないので、**複数の Debye 極を重ね合わせて ε″ を帯域内で平坦にする**しかない。

このスクリプトはそのパラメータを決定し、狙いどおり tanδ が一定になっていることを検証する。

> **「分散モデルで非分散を実現する」という一見ねじれた構成である。** gprMax の材料モデルの制約による技術的な回避策であり、物理的には非分散媒質そのものを表している。

---

## 2. なぜ tanδ 一定が重要か

減衰係数は低損失極限で

```
α ≈ π f n tanδ / c
```

なので、**tanδ が一定なら α ∝ f**（帯域 0.5–2.0 GHz で 4.0 倍）。σ 一定なら α は周波数に依存しない（帯域内比 1.0）。

この差が手法の成否を分ける。重心周波数シフトの恒等式

```
df_c/dt = −2π · tanδ · σ_f²
```

は **α ∝ f を前提**としており、α が周波数依存を持たなければ f_c は動かない。

| 損失モデル | ε″ の f 依存 | tanδ | α | f_c シフト |
|---|---|---|---|---|
| σ 一定（Level 2） | ∝1/f | ∝1/f | **一定** | **なし** |
| **tanδ 一定（Level 3）** | **一定** | **一定** | **∝ f** | **あり** |

つまり「非分散を正しく実装できるか」が、そのまま「重心周波数法が使えるか」に直結する。

---

## 3. 設計の原理

### 3.1 Debye 極の重ね合わせ

Debye 1 極の虚部は

```
ε″(ω) = Δε · (ωτ) / (1 + (ωτ)²)
```

で、**ω = 1/τ にピークを持つ山型**になる。τ を帯域の上下に振り分けて複数重ねると、山どうしが重なって**平坦部ができる**。

図 (a) がこれを示す。2 極の場合、緩和ピークは **0.386 GHz と 2.590 GHz** に置かれる。どちらも帯域（0.5–2.0 GHz）の**外側**にあるのが要点で、帯域端まで平坦にするにはピークを帯域外に出す必要がある。

### 3.2 最適化

最適化変数は `[Δε₁..Δε_n, log(τ₁)..log(τ_n)]`。τ を対数で扱うのは桁をまたぐ探索を安定させるため。

目的関数は帯域内 300 点での相対誤差。

```
residual = ε″_Debye(f) / ε″_target − 1
```

制約は gprMax の要求 τ > Δt に余裕を持たせて **τ > 2Δt**。

### 3.3 ε_∞ の決め方

Debye 極は ε′ を静的値から引き下げるので、その分を差し引いて ε_∞ を決める。

```
ε_∞ = ε_r − Δε′_drop(f_centre)
```

帯域中心で ε′ = 3.0 になるよう合わせている。ε′ の帯域内変動は 2 極で 0.40% と小さい。

### 3.4 目標 tanδ の決め方

Heiken/Carrier 経験式（450 MHz 版）から与える。

```
tanδ = 10^(0.033·(FeO+TiO2) + 0.231·ρ − 3.061)
```

密度は ε′ から一意に決まる。

```
ε′ = 1.843^ρ = 3.0    →    ρ = 1.796895
```

> **非分散なので「どの周波数で ε′ = 3.0 か」という但し書きが不要**になる点に注意。分散性モデル（Level 3b）では ε′ 自体が周波数依存になるため、基準周波数を決める必要があった。
>
> また **ε′ は組成に依らない**ので、全組成で密度・走時・幾何減衰が共通になる。違いは吸収だけなので、組成の効果だけを切り出して比較できる。

## 4. 極数の選択

| 極数 | ε″ RMS 誤差 | tanδ p-p | ε′ p-p | α 帯域内比 | 最小 τ/Δt | 判定 |
|---|---|---|---|---|---|---|
| 1 | 6.609% | 21.78% | 0.52% | 4.010 | 27.0 | OK |
| **2** | **0.193%** | **1.12%** | 0.40% | **4.008** | **10.4** | **OK** |
| 3 | 0.005% | 0.38% | 0.37% | 4.007 | 6.6 | OK |
| 4 | 0.000% | 0.36% | 0.36% | 4.007 | 4.9 | τ 小 |

**2 極を採用**する。理由は次のとおり。

- 1 極では tanδ の変動が 21.8% あり、非分散とは言えない
- 2 極で ε″ 誤差 0.19%、tanδ 変動 1.1% まで落ち、実用上十分
- 3 極以上にしても α 帯域内比はほとんど改善しない（4.008 → 4.007）
- **極数を増やすと最小 τ が小さくなり、gprMax の制約に近づく**（4 極では τ/Δt = 4.9）

図 (d) がこのトレードオフを示す。精度（赤）と gprMax 制約（青）が逆方向に動くため、両者が交差する 2 極が最適点になる。

## 8. 既知の制約と注意

| 項目 | 内容 |
|---|---|
| ε′ の変動 | 2 極で 0.40%。完全な非分散ではないが、走時への影響は 0.2% 程度 |
| 帯域外の挙動 | 帯域外では ε″ が落ちる。帯域外の成分が問題になる場合は極を増やすか帯域を広げる |
| Kramers-Kronig | Debye 極は KK 関係を自動的に満たすので、ε′ と ε″ の整合は保証される |
| 低損失近似 | α の式は厳密式を使っているが、α ∝ f は低損失極限の関係。tanδ ≈ 0.004 では誤差 10⁻⁵ 未満 |

### なぜ ε′ を完全に一定にできないか

Kramers-Kronig の関係により、**ε″ が周波数依存を持てば ε′ も必ず変化する**。ε″ を帯域内で平坦にしても帯域外では落ちるので、その影響が ε′ に現れる。

これは物理的に避けられない制約であり、実在の非分散媒質も厳密には ε′ が一定ではない。0.40% の変動は実用上無視できる。

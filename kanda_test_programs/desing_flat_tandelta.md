# design_flat_tandelta.py

帯域内で **tanδ を一定に保つ多極 Debye パラメータ**を設計し、その妥当性を図で説明するツール。

---

## 1. 何のためのツールか

月南極のレゴリス（イルメナイト <1 wt%）は**非分散**である。すなわち帯域内で

```
ε′  = 一定
ε″  = 一定       →       tanδ = ε″/ε′ = 一定
```

これを gprMax で実現したいが、**gprMax の材料モデルでは直接指定できない**。

```
#material: ε_r σ μ_r σ*    →    ε″ = σ/(ω ε₀) ∝ 1/f
```

σ 一定では tanδ が 1/f で落ちてしまう（これが Level 2）。gprMax は Debye / Lorentz / Drude しか持たないので、**複数の Debye 極を重ね合わせて ε″ を帯域内で平坦にする**しかない。

このスクリプトはそのパラメータを決定し、狙いどおり tanδ が一定になっていることを検証する。

> **「分散モデルで非分散を実現する」という一見ねじれた構成である。** gprMax の材料モデルの制約による技術的な回避策であり、物理的には非分散媒質そのものを表している。

---

## 2. なぜ tanδ 一定が重要か

減衰係数は低損失極限で

```
α ≈ π f n tanδ / c
```

なので、**tanδ が一定なら α ∝ f**（帯域 0.5–2.0 GHz で 4.0 倍）。σ 一定なら α は周波数に依存しない（帯域内比 1.0）。

この差が手法の成否を分ける。重心周波数シフトの恒等式

```
df_c/dt = −2π · tanδ · σ_f²
```

は **α ∝ f を前提**としており、α が周波数依存を持たなければ f_c は動かない。

| 損失モデル | ε″ の f 依存 | tanδ | α | f_c シフト |
|---|---|---|---|---|
| σ 一定（Level 2） | ∝1/f | ∝1/f | **一定** | **なし** |
| **tanδ 一定（Level 3）** | **一定** | **一定** | **∝ f** | **あり** |

つまり「非分散を正しく実装できるか」が、そのまま「重心周波数法が使えるか」に直結する。

---

## 3. 設計の原理

### 3.1 Debye 極の重ね合わせ

Debye 1 極の虚部は

```
ε″(ω) = Δε · (ωτ) / (1 + (ωτ)²)
```

で、**ω = 1/τ にピークを持つ山型**になる。τ を帯域の上下に振り分けて複数重ねると、山どうしが重なって**平坦部ができる**。

図 (a) がこれを示す。2 極の場合、緩和ピークは **0.386 GHz と 2.590 GHz** に置かれる。どちらも帯域（0.5–2.0 GHz）の**外側**にあるのが要点で、帯域端まで平坦にするにはピークを帯域外に出す必要がある。

### 3.2 なぜ対数等間隔なのか：連続極限が厳密に一定になる

これが平坦化の原理である。緩和時間を **ln τ に一様な密度 D** で連続分布させると

```
ε″(ω) = ∫ D · (ωτ)/(1+(ωτ)²) d(ln τ)
```

ここで u = ln(ωτ) と置くと ωτ = e^u、d(ln τ) = du であり、

```
(ωτ)/(1+(ωτ)²) = e^u/(1+e^{2u}) = 1/(e^{-u}+e^{u}) = ½ sech(u)
```

したがって

```
ε″(ω) = D ∫_{-∞}^{∞} ½ sech(u) du = D · π/2        ← ω に依存しない
```

**ln τ 一様分布なら ε″ は厳密に一定**になる。∫½sech(u)du = π/2 はスクリプトの `continuum_flatness()` で数値的にも確認している。

有限個の Debye 極は、この連続分布を**離散サンプル**していることになる。だから対数等間隔に置けば平坦に近づく。極数を増やすほど連続極限に近づき、実際 §4 の表で ε″ 誤差が 6.6% → 0.19% → 0.005% と急速に落ちる。

### 3.3 2 極の場合は解析解がある

有限個の場合、最適な間隔と振幅は**閉じた形で求まる**。

帯域の幾何中心を ω_c = √(ω_lo ω_hi) とし、**u = ln(ω/ω_c)** と置く。2 極を ω_c e^{±s} に対称配置し、振幅を等しく Δε とすると、§3.2 の変形から

```
ε″(u) / Δε = ½ [ sech(u − s) + sech(u + s) ]
```

という双曲線関数の和になる。u について偶関数なので、中心 u=0 で 1 階微分は自動的にゼロ。**2 階微分もゼロにする**のが最大平坦（maximally flat）条件である。

```
d²/du² sech(x) = sech(x) [ tanh²(x) − sech²(x) ]
```

なので

```
g″(0) = sech(s) [ tanh²(s) − sech²(s) ] = 0
```

`sech(s) ≠ 0` より `tanh²s = sech²s`、両辺に cosh²s を掛けて

```
sinh²s = 1    →    sinh s = 1    →    s = arcsinh(1) = ln(1 + √2) = 0.881374
```

**緩和周波数の比**は

```
e^{2s} = (1 + √2)² = 3 + 2√2 = 5.828427
```

**振幅**は、中心での値が sech(s) = 1/√2 なので、目標に合わせて

```
Δε = √2 · ε″_target        （各極）
```

まとめると、2 極の解析解は次のとおり。

| 量 | 閉じた形 | 値（帯域 0.5–2.0 GHz） |
|---|---|---|
| 帯域幾何中心 | f_c = √(f_lo f_hi) | 1.0000 GHz |
| 極の間隔 | s = ln(1+√2) | 0.881374 |
| 緩和周波数 | f_c/(1+√2), f_c(1+√2) | 0.4142, 2.4142 GHz |
| 緩和時間 | 1/(2πf) | 384.23, 65.92 ps |
| 振幅（各極） | Δε = √2 · ε″_target | 0.016952 |

**すべて √2 で書ける**のが特徴である。

### 3.4 数値解はこれを精密化したもの

解析解は「帯域中心で最大平坦」を狙ったもので、**帯域端の誤差は考慮していない**。有限帯域全体で誤差を最小化すると、少し違う解になる。

| | s | 緩和周波数比 | Δε | ε″ RMS 誤差 | tanδ p-p |
|---|---|---|---|---|---|
| **解析解**（最大平坦） | 0.8814 | 5.828 | 0.016952 | 0.850% | 2.69% |
| **数値解**（等リップル） | 0.9518 | 6.707 | 0.017796 | **0.193%** | **1.12%** |

図 (d) がこの違いを示す。解析解は中心付近で誤差ゼロだが帯域端で −2.5% まで落ちる。数値解は帯域全体に誤差を均等配分し（等リップル）、最大偏差が ±0.25% に収まる。**フィルタ設計における Butterworth（最大平坦）と Chebyshev（等リップル）の関係**とまったく同じ構図である。

RMS で見ると数値解が 4.4 倍優れるので、**実装には数値解を採用**する。ただし解析解には次の役割がある。

- **最適化の初期値**として使える（収束が速く安定する）
- **検算**に使える。数値解が解析解から大きく外れていたら、最適化が局所解に落ちている
- **設計の見通し**を与える。s や Δε が帯域幅にどう依存するかが式で分かる

### 3.5 3 極以上に等振幅の解析解はない

同じ手続きを 3 極（u = 0, ±s に配置、等振幅）に適用すると

```
g″(0) = ½ [ sech″(0) + 2 sech″(s) ] = ½ [ −1 + 2 sech(s)(tanh²s − sech²s) ]
```

第 2 項の最大値は 0.544 で、`−1` を打ち消せない。つまり**等振幅では最大平坦条件を満たす s が存在しない**（中心極の負の曲率が大きすぎる）。中心極の振幅を下げる必要があり、等振幅の仮定が崩れる。

したがって 3 極以上は**数値最適化が必須**である。スクリプトが数値解法を採っているのはこのためでもある。

### 3.6 ε_∞ の決め方

Debye 極は ε′ を静的値から引き下げるので、その分を差し引いて ε_∞ を決める。

```
ε_∞ = ε_r − Δε′_drop(f_centre)
```

帯域中心で ε′ = 3.0 になるよう合わせている。ε′ の帯域内変動は 2 極で 0.40% と小さい。

### 3.7 目標 tanδ の決め方

Heiken/Carrier 経験式（450 MHz 版）から与える。

```
tanδ = 10^(0.033·(FeO+TiO2) + 0.231·ρ − 3.061)
```

密度は ε′ から一意に決まる。

```
ε′ = 1.843^ρ = 3.0    →    ρ = 1.796895
```

> **非分散なので「どの周波数で ε′ = 3.0 か」という但し書きが不要**になる点に注意。分散性モデル（Level 3b）では ε′ 自体が周波数依存になるため、基準周波数を決める必要があった。
>
> また **ε′ は組成に依らない**ので、全組成で密度・走時・幾何減衰が共通になる。違いは吸収だけなので、組成の効果だけを切り出して比較できる。

## 4. 極数の選択

| 極数 | ε″ RMS 誤差 | tanδ p-p | ε′ p-p | α 帯域内比 | 最小 τ/Δt | 判定 |
|---|---|---|---|---|---|---|
| 1 | 6.609% | 21.78% | 0.52% | 4.010 | 27.0 | OK |
| **2** | **0.193%** | **1.12%** | 0.40% | **4.008** | **10.4** | **OK** |
| 3 | 0.005% | 0.38% | 0.37% | 4.007 | 6.6 | OK |
| 4 | 0.000% | 0.36% | 0.36% | 4.007 | 4.9 | τ 小 |

**2 極を採用**する。理由は次のとおり。

- 1 極では tanδ の変動が 21.8% あり、非分散とは言えない
- 2 極で ε″ 誤差 0.19%、tanδ 変動 1.1% まで落ち、実用上十分
- 3 極以上にしても α 帯域内比はほとんど改善しない（4.008 → 4.007）
- **極数を増やすと最小 τ が小さくなり、gprMax の制約に近づく**（4 極では τ/Δt = 4.9）

図 (d) がこのトレードオフを示す。精度（赤）と gprMax 制約（青）が逆方向に動くため、両者が交差する 2 極が最適点になる。

## 8. 既知の制約と注意

| 項目 | 内容 |
|---|---|
| ε′ の変動 | 2 極で 0.40%。完全な非分散ではないが、走時への影響は 0.2% 程度 |
| 帯域外の挙動 | 帯域外では ε″ が落ちる。帯域外の成分が問題になる場合は極を増やすか帯域を広げる |
| Kramers-Kronig | Debye 極は KK 関係を自動的に満たすので、ε′ と ε″ の整合は保証される |
| 低損失近似 | α の式は厳密式を使っているが、α ∝ f は低損失極限の関係。tanδ ≈ 0.004 では誤差 10⁻⁵ 未満 |

### なぜ ε′ を完全に一定にできないか

Kramers-Kronig の関係により、**ε″ が周波数依存を持てば ε′ も必ず変化する**。ε″ を帯域内で平坦にしても帯域外では落ちるので、その影響が ε′ に現れる。

これは物理的に避けられない制約であり、実在の非分散媒質も厳密には ε′ が一定ではない。0.40% の変動は実用上無視できる。

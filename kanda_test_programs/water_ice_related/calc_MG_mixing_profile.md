# calc_MG_mixing_profile.py

**位置づけ**：`calc_LLL_mixing_profile.py`（LLL 混合則版）の**対照実験**
**目的**：結果の混合則依存性を切り分ける
**版**：1.1（氷の描像を 2 通りに拡張）

---

## 1. なぜ作るのか

LLL 版で採用した「**氷は空隙を埋める**」という描像は、混合則の選択とは独立の物理的判断である。しかし得られた結論（氷 1 vol% で ε′ が +0.95%、界面反射 −52.5 dB）が**混合則の選び方に強く依存する**なら、その結論は信用できない。

そこで**同じ体積分率の考え方**を Maxwell-Garnett (MG) 則に適用し、傾向が一致することを確認する。

### MG が適用範囲外であることは承知のうえ

MG は「連続な母材の中に孤立した介在物が薄く分散している」ことを前提とする。レゴリスは空隙率 30–45% で粒子も空隙も連続相と呼べる状態なので、**本来は適用範囲外**である。また MG は母材と介在物を区別する非対称な式なので、「どちらを母材と呼ぶか」という恣意性が入る（LLL や対数混合は対称なのでこの問題がない）。

したがって本スクリプトの目的は「MG のほうが正しい」ことを示すことではなく、**適用範囲外の規則を使っても傾向が変わらないことを確認する**ことにある。

---

## 2. 体積分率の考え方（LLL 版と共通）

**氷の描像を 2 通り用意している**（`ICE_MODEL`。LLL 版で定義され、MG 版はそれを参照する）。

### `'pore'` 吸着水描像（空隙充填）

```
v_grain = rho(z) / rho_grain                     氷量に依らない
v_void  = 1 - v_grain - v_ice
```

氷は**空隙（真空）だけを置き換える**。粒子の量は変わらない。

### `'excess'` 過剰氷描像（バルク置換）

```
v_grain = (1 - v_ice) * rho(z) / rho_grain
v_void  = (1 - v_ice) * (1 - rho(z)/rho_grain)
```

氷が**レゴリス（粒子＋空隙）をまるごと押しのける**。粒子も空隙も (1−v_ice) 倍になる。

粒子密度は斜長岩の 2.645 g/cm³（LLL 版と共通）。虚部は `'pore'` で保存、`'excess'` で (1−v_ice) 倍に希釈する（粒子が減るため）。

---

## 3. MG の適用形

多成分 MG は母材 ε_h に対して

```
(eps_eff - eps_h)/(eps_eff + 2 eps_h) = sum_i v_i (eps_i - eps_h)/(eps_i + 2 eps_h)
```

と書ける。S = Σ vᵢβᵢ と置けば

```
eps_eff = eps_h (1 + 2S)/(1 - S)
```

### 3.1 母材の選択（`MG_HOST`）

| 値 | 内容 |
|---|---|
| `'void'`（既定） | 真空を母材、粒子と氷を介在物とする |
| `'grain'` | 粒子を母材、空隙と氷を介在物とする |

どちらも「適用範囲外だがやってみる」という位置づけ。**両方試して差を見ることに意味がある**（§6）。

### 3.2 粒子誘電率の決め方（`MG_GRAIN_MODE`）

MG では乾燥時の ε′ が Carrier の 1.871^ρ と一致しないので、ε_grain をどう決めるかで結果が変わる。

| 値 | 内容 |
|---|---|
| **`'per_depth'`（既定）** | 各深さで「乾燥時の MG が Carrier の ε′ に一致する」よう ε_grain を逆算する。**乾燥プロファイルが LLL 版と厳密に一致する**ので、2 つの出力の差は氷の項だけになる。混合則依存性を見るのが目的なのでこれが本命 |
| `'fixed'` | 基準深さ（既定 0.5 m）で一度だけ較正し、以後は固定。素直な MG モデルだが、乾燥プロファイル自体が Carrier からずれるので、そのずれも一緒に見えてしまう |

`MG_HOST='void'` なら逆算は閉形式で解ける。

```
S = (eps_eff - 1)/(eps_eff + 2),  beta_g = S / v_grain
eps_grain = (1 + 2 beta_g)/(1 - beta_g)
```

`'grain'` は ε_grain が式のあちこちに現れるので `brentq` で数値的に解く。

### 3.3 虚部の扱い（`MG_EPS_IMAG_MODE`）

**既定は `'conserved'`（LLL 版と同じ）。**損失は鉱物粒子で発生し、空隙に氷が入っても粒子の量は変わらないので ε″ は保存する（氷自身の微小な損失だけを加える）。これは**混合則とは独立の物理的判断**なので、MG 版でも同じ扱いにする。

虚部に混合則を適用すると「損失源が増えていないのに減衰が増える」という非物理的な結果になる。比較のため `'complex_mg'` で複素 MG も試せるようにしてある。

### 3.4 分散の扱い（LLL 版と共通）

ε″ は帯域内で一定。`Level_3.in` と同じ**最大平坦 2 極 Debye の解析解**で実現する。LLL 版の `dry_eps_complex()` をそのまま使うので自動的に揃う。

実部への氷の効果は、乾燥／湿潤の MG の**比**として掛ける。

```
eps'_wet(f) = eps'_dry(f) * [ mg_wet / mg_dry ]
```

比で入れるのは、Debye 実現による帯域内のわずかな周波数依存を壊さないため。`MG_GRAIN_MODE='per_depth'` なら `mg_dry` は Carrier の ε′ に一致するので、この比は素直に「氷による増分」だけを表す。

## 4. 実装方針

物理定数・作図・検算はすべて `calc_LLL_mixing_profile.py` から import して使い、**混合則の部分だけを差し替える**。定数を 2 か所に書かない（修正項目 A-1 と同じ事故を防ぐ）。

差し替えるのは **`medium_eps()` ただ 1 つ**。

```python
import calc_LLL_mixing_profile as base

base.medium_eps = medium_eps_mg      # これだけで全計算が MG になる
base.OUTPUT_BASE = OUTPUT_BASE
base.MIXING_LABEL = 'MG'
base._prop_cache.clear()
base._moments_cache.clear()
base.SET_FREQ = base.build_profile_set(base.PAIRS_FREQ)
base.SET_COMP = base.build_profile_set(base.PAIRS_COMP)
```

`build_profile_set` / `alpha_velocity` / `propagation_table` はすべてモジュール globals 経由で `medium_eps` を引くので、置き換えれば以降の計算はすべて MG 版になる。

> **LLL 版への変更**：混合則の名前を `MIXING_LABEL` / `MIXING_DESC` という変数にして、図のタイトルと検算文で共通に使うようにした。MG 版から差し替えられるようにするため。

## 6. 結果：混合則依存性はどれくらいか

深さ 1.5 m、1.00 GHz、FeO+TiO2 = 7.5 wt%。

| 混合則 | ε_grain@1.5 m | 乾燥時の誤差 | d(ε′)/vol% | R(1 vol%) | R(10 vol%) |
|---|---|---|---|---|---|
| MG（母材＝真空、per_depth） | 5.5517 | 4.4e-14 % | **+1.184** | **−50.6 dB** | −30.5 dB |
| MG（母材＝真空、fixed） | 5.5625 | 0.29 % | +1.184 | −50.6 dB | −30.5 dB |
| **LLL（本命）** | — | 0 | **+0.952** | **−52.5 dB** | **−32.6 dB** |
| MG（母材＝粒子、per_depth） | 4.4573 | 4.4e-14 % | **+0.827** | **−53.7 dB** | −33.9 dB |
| MG（母材＝粒子、fixed） | 4.3705 | 6.67 % | +0.836 | −53.6 dB | −33.8 dB |

### 読み取れること

**(1) LLL は 2 つの MG のちょうど間に入る。**母材を真空にすると氷の効果が強く、粒子にすると弱く出る。LLL は対称な規則なので中間になるのが自然。

**(2) 全体の振れ幅は 3.1 dB。**界面反射で −50.6 〜 −53.7 dB。

**(3) これは「描像の違い」の 26 dB に比べて 1 桁小さい。**

| 選択 | 界面反射への影響（1 vol%） |
|---|---|
| **氷が空隙を埋めるか／レゴリスを置き換えるか** | **26 dB** |
| 混合則と母材の選び方 | **3.1 dB** |
| 虚部を保存するか複素 MG にするか | 0.0 dB（実部への影響なし） |

> **結論**：結果は混合則にほとんど依存しない。**重要なのは規則ではなく描像**である、という LLL 版で述べた主張が定量的に裏づけられた。

**(4) `fixed` と `per_depth` は氷の増分にはほとんど効かない。**ただし乾燥プロファイル自体の誤差は母材＝粒子で 6.67% に達する。MG の関数形（有理式）が Carrier の指数形と合わないためで、**MG が適用範囲外であることの直接的な現れ**でもある。

## 7. 使い方

```bash
python calc_MG_mixing_profile.py
```

`calc_LLL_mixing_profile.py` と同じディレクトリに置くこと（import する）。

### 主な設定（ファイル先頭の `[EDIT HERE]`）

| 変数 | 既定 | 備考 |
|---|---|---|
| `OUTPUT_BASE` | SSD 上の `MG_mixing_profile` | LLL 版と並べて比較できるよう別ディレクトリ |

## 8. 既知の制約

| 項目 | 内容 |
|---|---|
| **適用範囲外** | MG は希薄・孤立介在物を前提とする。空隙率 30–45% のレゴリスには本来使えない。承知のうえで対照実験として使う |
| 母材の恣意性 | MG は非対称な式なので母材の選択が必要。真空と粒子で 3.1 dB 違う |
| 乾燥プロファイルの再現 | `per_depth` なら厳密に一致するが、ε_grain が深さ依存になる（物理的には不自然）。`fixed` なら物理的には素直だが Carrier からずれる |
| `complex_mg` | 虚部にも混合則を適用する比較用モード。損失源が増えていないのに減衰が変わりうるので既定にはしない |
| LLL 版への依存 | `medium_eps` の signature が変わると壊れる。LLL 版を変更したら本スクリプトも確認すること |

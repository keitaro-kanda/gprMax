# design_flat_tandelta.py

**版**：2.0（解析解のみ・Carrier Fig. 9.53 に更新）
**対象**：`Level_N.in` の Debye パラメータ設計ロジックの理論解説と作図

---

## 1. 何のためのツールか

月南極のレゴリス（イルメナイト <1 wt%）は、GPR 帯域 0.5–2.0 GHz で **ε″ が一定**である。これを gprMax で実現するための Debye パラメータを決め、その設計思想を図と数値で説明する。

> **実際のパラメータ設定は `Level_N.in` の中で完結している。**本スクリプトは `.in` と同じ式・同じ定数を使って**理論解説用の図と検算表を出す**ためのもので、`.in` の入力を作るものではない。したがって `.in` を変更したら本スクリプトも必ず合わせること（値を 2 か所で持たない）。

### 用語について

**「非分散」という語は使わない。**ε″ ≠ 0 の媒質は Kramers-Kronig 則により ε′ が必ず対数的に変化するため、厳密な意味で非分散な損失媒質は存在しない。正しい記述は

> **ε″ = 一定（帯域内）、ε′ は KK により約 0.4% 変化**

である。

### なぜ Debye 極を重ねるのか

gprMax の材料モデルは

```
#material: eps_r sigma mu_r sigma*     ->  eps'' = sigma/(w eps0)  ∝ 1/f
```

しか与えず、σ 一定では ε″ が 1/f で落ちてしまう（これが Level 2）。Debye / Lorentz / Drude しか使えないので、**複数の Debye 極を重ねて ε″ を平坦にする**しかない。

---

## 2. なぜ ε″ 一定が重要か

減衰係数は低損失極限で

```
alpha ≈ pi f n tan_delta / c
```

なので、**ε″ 一定なら α ∝ f**（帯域 0.5–2.0 GHz で 4.0 倍）。一方 σ 一定なら α は周波数に依存しない（帯域内比 1.0）。

α が周波数依存を持つことは、重心周波数シフト法が機能するための必要条件である。

```
df_c/dt = -2 pi tan_delta sigma_f^2      （α ∝ f を前提とする）
```

したがって「ε″ 一定」を正しく実装できるかどうかが、手法の成立可否を分ける。

---

## 3. 設計の原理

### 3.1 Debye 極の重ね合わせ

1 極の ε″ は

```
eps''(w) = De * (w tau) / (1 + (w tau)^2)
```

で、w = 1/τ にピークを持つ山型になる。対数周波数 u = ln(ωτ) で書くと

```
eps''(u) / De = (1/2) sech(u)
```

と**左右対称の山**になる。したがって τ を帯域の上下に振り分けて重ねると、山どうしが重なって平坦部ができる。

### 3.2 なぜ対数等間隔なのか：連続極限が厳密に一定

ln τ に一様な密度 D で無限に分布させると

```
eps''(w) = int D (w tau)/(1 + (w tau)^2) d(ln tau)
         = D int (1/2) sech(u) du = D pi/2
```

と**厳密に周波数に依らなくなる**。有限個の極はこの連続分布を離散サンプルしていることになる。スクリプトはこの積分を数値で確認する（π/2 = 1.570796327）。

### 3.3 2 極の解析解（採用する設計）

緩和周波数を f₀ e^(±s) に対称配置し、振幅を等しく Δε とすると

```
eps''(u) / De = (1/2) [ sech(u - s) + sech(u + s) ]
```

中心 u = 0 での 2 階微分をゼロにする（**最大平坦条件**）と

```
sinh s = 1   ->   s = arcsinh(1) = ln(1 + sqrt(2)) = 0.881374
```

となり、緩和周波数比は **e^(2s) = 3 + 2√2 = 5.828427** に決まる。中心での値は sech(s) = 1/√2 なので、目標に合わせるには

```
De = sqrt(2) * eps''_target      （各極）
```

さらに、**対称中心を帯域の幾何平均 f₀ = √(f_lo f_hi) に取る**と、ω₀τ₁ = √2 − 1、ω₀τ₂ = √2 + 1 なので

```
1/(1 + (w0 tau_1)^2) + 1/(1 + (w0 tau_2)^2) = 1     （厳密に 1）
```

が成り立つ。したがって f₀ で ε′ = ε_r にするための ε_∞ も閉形式になる。

```
eps_inf = eps_r - De
```

**設計はこの 4 行だけで完結する。**最適化ソルバも初期値も収束判定も要らない。

```
f0      = sqrt(f_lo * f_hi) = 1.0 GHz
tau_1,2 = 1/(2 pi f0 (1+sqrt2)),  (1+sqrt2)/(2 pi f0)
De      = sqrt(2) * eps''_target
eps_inf = eps_r - De
```

### 3.4 数値最適化を使わない理由（版 2.0 での変更）

旧版は `least_squares` で等リップル解を求めていた（ε″ 誤差 RMS 0.19%、解析解 0.85%）。精度は高いが、

- 論文で式を一行で書けない
- ソルバの初期値・収束条件が結果に影響する
- `.in` の中で scipy を使うことになる

ため採用をやめた。解析解の誤差が振幅に与える影響は深さ 2.75 m で約 **−0.06 dB** であり、合否判定幅 ±0.5 dB に対して十分小さい。

> **正直に書くべき点**：最大平坦条件は「中心で最も平ら」であって「帯域全体のリップル最小」ではない。s を数値的に振ると **s = 0.9620 で p-p 0.63%** となり、arcsinh(1) の **2.44%** より 4 倍良い。ただし振幅への影響は −0.015 dB 対 −0.06 dB でどちらも判定幅の 1/10 以下なので、**閉形式で書けることを優先**して arcsinh(1) を採用している。精度を優先するなら s を差し替えればよいが、その値は帯域幅に依存し閉形式では書けない。

### 3.5 α 比は平坦さの判定に使えない

帯域端 f_lo と f_hi は f₀ に対して対称なので、**対称配置なら ε″ は両端で必ず等しくなる**。そのため α の帯域内比は 1 極でも 4.0 になり、平坦さの判別に使えない。平坦さは **p-p** で見ること。

| 設計 | ε″ RMS | ε″ p-p | tanδ p-p | α 比 |
|---|---|---|---|---|
| 1 極（比較用） | 9.44% | 20.00% | 21.77% | 4.010 |
| **2 極（採用）** | **0.85%** | **2.44%** | **2.71%** | 4.009 |

### 3.6 目標 ε″ の決め方

```
eps'  = 3.0（設計判断。f0 における値）
  -> rho = ln(3.0)/ln(1.871) = 1.753647          Carrier Fig. 9.53
  -> tan_delta = 10^(0.027 S + 0.273 rho - 3.058)
  -> eps''_target = eps' * tan_delta
```

**経験式の出典**：Carrier, Olhoeft & Mendell (1991), Lunar Sourcebook Ch.9, **Fig. 9.53（SOILS = 土壌試料のみの回帰）**の図中式。

Fig. 9.53 を選ぶ理由は 3 つ。

1. 本研究の対象はレゴリス（土壌）であり、岩石片を含む Fig. 9.52 (ALL DATA) や Fig. 9.54 (450 MHz DATA) より母集団が適切
2. tanδ の周波数依存を無視する立場をとる以上、**周波数で切ったサブセット（Fig. 9.54 = 450 MHz）を選ぶのは仮定と矛盾する**。選ぶべき軸は周波数ではなく試料種別
3. 土壌データは ρ ≈ 1.0–2.1 に分布し、ρ = 1.753647 はその中心付近（内挿であって外挿でない）

> **ε′ の式と tanδ の式は同一図・同一サブセットから取ること。**片方だけ他図の式に差し替えると自己整合が崩れる。

参考（本スクリプトでは使わない）：

| 図 | サブセット | ε′ の基底 | tanδ の 3 次元回帰 |
|---|---|---|---|
| 9.52 | 全試料 | 1.919 | 10^(0.038·S + 0.312ρ − 3.260) |
| **9.53** | **土壌のみ（採用）** | **1.871** | **10^(0.027·S + 0.273ρ − 3.058)** |
| 9.54 | 450 MHz のみ | 1.843 | 10^(0.033·S + 0.231ρ − 3.061) |
| 9.55 | Apollo 15–17 | 1.908 | 10^(0.028·S + 0.167ρ − 2.975) |

なお ρ = 1.753647 は Carrier の密度プロファイル ρ(z) = 1.92(z+12.2)/(z+18) [z: cm] の**深さ約 49 cm** に相当するので、「深さ 50 cm 付近のレゴリスを一様に敷き詰めた媒質」と解釈できる。

## 5. なぜ ε′ を完全に一定にできないか

ε″ ≠ 0 の媒質は **Kramers-Kronig 則により ε′ が必ず対数的に変化する**。帯域全体では

```
Delta eps' = -(2/pi) * eps'' * ln(f_hi/f_lo)
```

が下限になる。7.5 wt% では KK 極限 0.011120 に対し 2 極解析解の実測が 0.013038（比 1.17）。

**これは近似の粗さではなく物理である。極数を増やしてもこの量は消えない**（極数を増やすほど KK 極限に収束するだけ）。したがって

- **`.in` は f₀ = 1.0 GHz で ε′ = 3.0 になるよう ε_∞ を決める**（基準周波数が必要）
- **解析コードの理論も ε′(f) を使う**（修正項目 A-3）

という扱いになる。「どの周波数で ε′ = 3.0 か」という但し書きは**必要**であり、旧版 README §3.7 の「非分散なので但し書きが不要」という記述は誤りだったので削除した。

## 8. 既知の制約と注意

| 項目 | 内容 |
|---|---|
| 最大平坦 ≠ リップル最小 | s = 0.9620 なら p-p 0.63%（arcsinh(1) は 2.44%）。閉形式を優先して後者を採用（§3.4） |
| α 比は判別に使えない | 帯域端が f₀ に対称なので 1 極でも 4.0 になる（§3.5） |
| ε′ は一定にできない | KK が要求する物理。基準周波数 f₀ が必要（§5） |
| 3 極以上 | 等振幅・対称の閉形式は 2 極までしかない。3 極以上は数値解が必要になるため扱わない |
| 経験式の不確かさ | Fig. 9.52–9.55 の振れ幅は 5–10 wt% で 0.80–1.09 倍。N_eff で 0.9–1.5 倍 |
